## 项目定位

本项目以复杂群体组织为共同研究对象，探索组成部分的相互作用如何形成、维持和改变整体结构与能力。在这一通用基础上，《开放经济学》重点解释人类社会怎样组织生产与协作、承担成本、协调分散知识、分配回报，并持续维护共同依赖的成果。Open Business 是经济领域的候选制度应用，AutoOS 是将其具体化并检验的场景。

项目继续追求从基础物理规律和少量可检验的交互假设发展通用组织理论。通用性首先体现为可以明确比较的对象、机制、条件和预测；哪些更强结论能跨越物理、生命与社会系统，需要逐步推导与验证。当前共同框架、继承的科学结果和有限模型，尚未组成解释所有组织的封闭公理体系。

书籍与理论研究并行。书籍围绕读者的问题建立解释，论文通过综述、概念分析、形式模型和经验研究承担相应证明责任。两条路线共享定义、命题及证据；论证强度随研究更新，不由书稿叙述预先决定。

同日收束补充：竞争与合作作为相互关联的组织过程共同研究，贯穿关系形成、维持、选择、纠错与演进。每次说明任务、层级、规则和期间；两者与Ordo的关系通过具体机制与能力结果建立，不预设固定正负效应。采用[统一术语接口](../shared/concept-interfaces.md)、[组织与经济连接](../research/reviews/33-organization-and-economic-interfaces.md)和[候选逐章提纲](../book/outline.md)推进；仍属0.3草案补充，不改变正式79条理论基线。

## 全书的核心问题

当前执行更新：组织形成、价格／收入研究后，已补[信用、投资与维护回流](../research/reviews/36-credit-investment-feedback-and-maintenance.md)，新增第五部分第6章。全书现有十一章讨论稿，基础综述已实际预检索，经济机制继续按定向单元补证；未称金融、宏观或制度验证全部完成，正式总表仍不变。

共同问题是：**在给定环境和资源条件下，多个组成部分怎样通过关系和交互获得能够持续的整体能力？在人类经济中，又怎样把分散的收益连接到持续投入、协作和回报？**

| 问题 | 本阶段的具体研究任务 |
|---|---|
| Q1 什么算组织 | 指定性质、组成分解、关系、边界与尺度，识别关系作用及选择研究单元的理由 |
| Q2 组织怎样持续 | 区分保持、调节、构成维护、自维持和适应，说明维护者与外部支持 |
| Q3 信息与能力如何度量 | 分开熵、统计信息、预测结构和任务表现，建立有条件的联系 |
| Q4 模块和层级为何出现 | 分开结构形成、局部变更、保存、接口与协调收益，比较其代价和失效情形 |
| Q5 记忆与复用怎样改变能力 | 说明记录怎样进入预测、行动、验证和更新，计算全周期投入及共同错误 |
| Q6 怎样进入社会经济 | 增加主体、偏好、信息、权利、承诺、外部选择与执行条件 |
| Q7 共享怎样获得持续投入 | 在同质量和期限下比较贡献、筹资、补充服务、赞助及组合安排 |

这些是研究依赖，不是所有组织必经的演进阶梯。经济应用可以帮助选择基础问题，基础论文也可不以 Open Business 为结论。

## 定义与最小理论基础

### 组织的工作口径

在声明的组成分解、研究性质、环境、尺度及精度下，关系与约束安排对目标结果具有可辨认、可解释的作用，称其对该性质具有有组织性。组织单元是为解释这种作用而选择的部分及关系，边界需要理由，也允许重叠、嵌套和暂时性。

这个定义不预设共同目的、非线性、整体增益、主动自保、增长、记忆或层级。简单回路也可具有有组织性；复杂群体还需描述部件差异、关系和过程的具体复杂性。工作定义为比较提供语言，组织是否存在某种作用与能力仍需证据。见 DEF-01至DEF-03。

### 持续 调节与自维持

持续保持某种结果、调节任务误差，以及维护产生结果的机制，是不同问题。自维持作为范围限定的能力：先列关键构成条件、损失、维护路径、维护者及外部支持，再检查这些关系能否在给定期间和扰动下支持声明的组织条件。

维护不要求把一切材料和服务都内生化，也不自动包含增长、复制或适应。采用更强的生命组织理论时，保留该理论的专门条件。见 DEF-04至DEF-06。

### 信息 结构与任务能力

热力学熵、Shannon熵、互信息、熵率、预测复杂性、结构统计和任务能力分别定义。涉及能力时明确任务、行动、预算、环境及期限，允许多维描述。对同一物理分布的熵换算、正则自由能与KL、特定复位下限等联系按 BASE 条件使用。

Ordo保留为待研究概念，未确立为通用标量、能量单位或价值尺度。统一描述不必预先等于统一数值；若提出新量，应证明它增加了什么解释或预测。见 DEF-07至DEF-13、BASE-01至BASE-05、HYP-01。

### 基本公设的地位

当前工作采用 **AX-01 物理实现**：具体组织、行动和制度运行通过物理过程实现，服从适用于其对象和条件的物理规律。这是继承性基础承诺，不是本项目的新定律，也不提供偏好、权利或公平标准的唯一答案。

组成与关系共同描述、声明尺度和对照、注明单位、区分模型与现实，是定义及研究要求；具体损失率、收益函数、行动规则和信息条件进入 ASS 项。首轮尚未建立非定义性的普遍群体行为新公设，后续须通过机制研究提出和收紧。

## 陈述的类型与论证责任

| 类型 | 负责说明什么 | 书稿中的使用 |
|---|---|---|
| 工作定义 DEF | 讨论什么，怎样识别与测量 | 明确本书口径及邻近概念，不以定义证明能力存在 |
| 基础承诺 AX与继承结果 BASE | 采用哪些基础条件及已有科学联系 | 带原有适用条件引用，不宣称新发现 |
| 领域与模型假设 ASS | 动力学、主体、信息、成本、规则等具体设定 | 把假设写在结论之前，说明现实对应与敏感性 |
| 条件命题 PROP | 从指定条件得到什么结果 | 分清解析推导、有限枚举、数值算例、反例和账户恒等式 |
| 待验证假说 HYP | 模型映射、跨系统推广和现实效果 | 给出可观察结果、失败条件和替代解释 |
| 哲学解释提案 | 意义等概念的一种理解及其理由 | 保留竞争立场与反例，不当作实验共识；现阶段不增加正式编号 |
| 目标与评价 NORM | 为什么选择开放、回报及某种权衡 | 公开价值理由，区分效率、分布、质量、风险与自主 |
| 参数与设计 PAR和DES | 候选费率、流程、预算和责任安排 | 标明未定稿、示例或实测状态，不反过来充当理论前提 |

已推导命题在模型条件下成立，不表示现实对象采用该模型；局部研究没有发现差异，也不证明所有关系均无作用。各类陈述的证据及依赖在共同总表中保留稳定编号。

## 本阶段可以发展的基本主张

### 关系的作用需要机制和对照

成员数、边数、相似性或相关性不足以确定组织能力。解释应指出具体作用及其改变结果的路径，同时说明比较时保留和改变了什么。Q1中继算例展示相同局部计数可以有不同端点传递，也可以在另一指标上相同。由此形成研究方法，不据此给组织排一条高低序列。

### 持续能力需要核对维护范围与速率

Q2模型说明，在所设损失与恢复方程下，维护通道及有效速率共同决定正能力平衡；有通道不保证维护充分，稳态存在也不等于结构起源已被解释。真实系统还要核对资源、执行上限、延迟、外部支持与维护者的持续条件。见 PROP-02、HYP-02。

### 模块和复用是有条件的能力机制

稳定中间成果可能缩小返工范围，接口可以限定部分依赖，记忆和复用可以减少重复投入；保存、组合、检索、验证、更新与治理同时需要成本。固定预算的耦合模型有局部与整体任务权衡，缓存模型也有净收益阈值。

这些线索继续构成本书的重要机制主线。它们不要求所有组织必然层级化，也不支持模块越多或记录越多就总是更好。形成原因、收益机制与现实采用分别论证。见 PROP-05至PROP-10、HYP-03至HYP-04。

### 信息收益通过行动和任务实现

保存完好的记录可能过时，有信息的系统也可能使用失配策略。特定对数增长任务可建立信息与收益的严格联系；在免费且允许保留原策略的条件下，新增信息不降低最优可达值。实际投入和净收益还依赖获取、解释、学习及实施成本，不能用bit直接定价。见 PROP-03至PROP-04、PROP-07至PROP-09。

### 经济协调需要同时解释能力 参与和执行

进入社会经济后，先说明谁能选择什么、掌握什么信息、承担什么成本、获得什么后果，以及有哪些外部选择和执行机制。完全自利、完全理性、完全信息和固定偏好都是可选简化，不能成为一切复杂组织的公设。

技术可行、正总收益、预算平衡、参与意愿、行动与报告激励、实际履约及规范接受分别检验。总额充足不等于有人愿意投入，覆盖成本也不等于所需努力获得激励。见 DEF-14至DEF-17、PROP-11至PROP-16。

### 开放合作需要把投入与回报具体连接

共享成果可以通过自愿贡献、条件筹资、补充服务和赞助获得投入，贡献者也可以有自用、学习等收益。经营收入扣除自身成本后，仍需要可信规则才转化为公共维护资金。相同期望收支不保证逐期履约，分散来源的效果要与储备、支付门槛及相关性共同判断。

这些是机制比较的入口。开放是否改善特定结果，需要同质量、同期限、同边界的替代方案与现实证据；公平性还取决于 NORM 所声明的标准。

## Open Business与AutoOS的应用定位

本项目研究的候选模式把保留和传播的成本共担、直接交易、共同技术服务及公共贡献支持结合起来。它有助于说明为何商业活动需要处理共同依赖的维护，以及普通贡献怎样拥有回报通道。其效果继续由应用研究检验。

AutoOS的工作映射分开资源本金、交易本金、公共回馈和平台运营用途；角色包括使用及出资者、内容贡献者、商家与服务方、运营者、预算与贡献复核职能，以及接受委托的维护者。资金授权、收到、承诺、分配、到账和追回分别记录。

直接交易回报、对过去贡献的奖励与对未来维护的报酬分别安排。维护委托写清对象、版本、范围、期限、资金、验收和交接；收到公共奖励不自动产生无限维护义务。平台软件和结算由运营安排承担，普通公共内容的维护需要相应自愿或受托关系。

5%技术费、50%公共回馈、首轮100人及分配指标均为候选。收费范围、含费口径、公共池资格、评审和治理权限尚需确定；各轮模型中的费用、概率与预算只是示例。不得把它们写成运营事实，或由成本共担直接推出低风险、由收藏数推出应得份额。见 PAR、DES及[Q8应用](../research/reviews/09-autoos-open-business.md)。

## 规范目标与论证边界

本项目支持知识复用、参与自主、公共贡献获得经济支持，以及可核对的规则与责任。这些目标应有独立的价值论证，并公开它们之间的取舍；它们不从热力学、总体最优或某种模型均衡自动产生。

人类路线另提出关系性意义解释及基本尊严不以收入、贡献或意义感为条件的价值方向供讨论。前者是哲学提案，后者是规范主张，均未升格为物理公设或加入正式79条总表。评价组织还应说明对个人生活、照料、实际选择及外部受影响者的后果；使命感不能替代必要报酬与维护预算。

热力学开放与制度开放、物理稳定与财务持续、技术接口与权利边界、记录数量与可靠知识、成本与价格、因果贡献与应得份额分别处理。对任何整体收益或改进的判断，明确谁被计入、观察期限、比较对象、代价和分布。

不采用自维持必然增长、普遍线性折旧、层级必然性、单调记忆棘轮、统一协调成本律或自然的Ordo能量换算作为既定公设。最大熵产生、内部预测器起源与自组织临界性等尚未完成的专题继续标明未确立，不用宽泛类比填补。

## 两条路线的安排

### 理论与论文路线

第一阶段的Q1–Q8定向阅读、有限模型和应用映射已完成首轮整理；这不等于复杂系统物理学的完整系统综述已经完成。下一阶段补齐所声明范围的检索和证据地图，继续区分原始定义、理论、经验结果、版本和未取得全文的线索。

机制论文优先选择维护、模块或复用中的一个有限问题，明确相对已有工作的贡献，补真实对象映射或更强解析条件。社会经济论文逐步加入偏好、信息、参与、契约与治理，保留同条件替代方案及失败情形。

AutoOS可以提供参数、案例和试点证据；实际研究另取得角色、收支、质量、退款、回报与维护资料，不用应用愿望替代基础理论的论证。

### 书籍路线

采用六部分结构：通用组织基础；作为组织的人；人际合作 规范与意义；多种人群组织；经济与开放合作；Open Business的应用。第一部分保留原组织基础及能力机制，第二至第三部分补入从人的维持、目标、合作与承诺到规则、权力及意义的连接。第四部分比较不同组织的成员、依赖、退出与维护，不把家庭到国家排成单向阶梯。

本次已形成第二、第三部分八章讨论稿与论证卡，见[章节目录](../book/README.md)。人的意义安排在第三部分末尾，回顾组织目的与个人生活的关系，并向后续组织比较和经济评价提出价值问题；它不把意义等同群体用途。原开篇保存为历史稿，原研究13–17保留来源与条件。

全书开篇仍可由“共享成果持续被使用，维护者却缺乏稳定支持”进入，再解释关系、维护、信息与制度。自然系统案例承担明确的比较任务，不要求先完成宇宙或生命的完整历史。

正文可以讲清已成立的有限结果，也可以讨论有理由的假说与制度目标，分别标明地位。重要解释引用统一编号及其来源；数学细节、参数及较长推导放入附录或研究文件。

后续工作是继续核查十一章的跨层连接与价值立场，以真实任务填共享服务的需求、成本、账期、责任和接替基线，并深化不同成员与权力结构的组织案例。财政、宏观风险与长期制度效果另有研究责任；基础综述在预检索后校准并开展完整筛选。既有Q1–Q8依据继续使用，不把书稿框架固定成不可修订的证明。

## 更新与阶段标准

共同总表为当前工作口径，历史讨论和各轮记录保持可追溯。定义、假设或证据改变时，检查依赖命题、书稿和应用；规范选择及应用参数的改变也应显式记录。

当前阶段以以下结果判断进展：对象及比较可识别，命题和条件可追溯，计算可复核，能够说明失败情形，真实映射有相应证据，制度目标和参数没有伪装成自然定律。新公设、新度量或新理论必须说明相对已有知识增加了什么。

本版先完成人类路线八章的结构修订，后续补第四部分开篇与第五部分第4、6章，现有十一章讨论稿。系统综述补齐、其余正文、现实校准及AutoOS试点仍分别推进。通用组织理论的更强成立范围与Open Business的实际有效性，继续由研究承担证明责任。
