# 全书范围与框架基线的边界

2026年11月12日。六部分、28候选单元维持，框架收束后不再以话题不断增加为进度标准。范围包括下列解释任务；深入证据与完整学科理论分层推进，不能借“另有论文”省略正文主张所需的关键前提。

截至第63轮，全书28个候选单元已有16章讨论稿、16张论证卡，余12个单元待起草。第一部分五章从辨认关系作用写到跨人传承，第5章承接到第二部分的身体与学习。[从集合到组织](part-01/01-from-collection-to-organization.md) · [第一部分通读记录](../research/reviews/63-from-collection-to-organization-chapter.md)

国际贸易、战争与地缘政治、人口转变、专门法律制度、疾病和医疗、完整美学与宗教哲学等，可以提供相关案例，也可以独立成研究。当前不承诺全面解释这些学科；只要全书某个核心主张依赖其具体结论，就必须在相应章节补足证据并写明范围。

本书将开放复用、人的机会、合理回报、可依赖的责任与可修订的治理作为需要论证的价值方向。它们可用于比较制度，却不被包装为从存续、总产出或Ordo自动产生的唯一目标。不可货币化的价值也不能只因不进入现金账而被排除。

框架内的未完成问题是有位置、有检验责任的研究工作；它们尚待解决的状态本身不等于目录有遗漏。若新结果表明既有位置掩盖无法成立的核心连接，应修订框架和版本说明，不能借“已经打标签”阻止研究。
