# 导言　十年以后，谁还用得上这张图？

想象你搬到一个陌生的小镇。房东见你推着婴儿车，送了你一张去车站的路线图。正门近，却有十几级台阶，得从面包店旁边的小门绕进去。照着走了一趟，你心想，这图真该多印几份。

画图的人也这么想。她把原稿留在网上，写明谁都可以下载、改画、送人。只要那道小门还开着，十年前花的一个下午，今天仍能帮你赶上车。偏偏有个周六，面包店隔壁围起了挡板。十份图可以印成一万份，那天推车的人却全绕到了同一处死胡同。

要让第一千零一个人走对路，还差什么？头一个碰壁的人已经在图底下留了言，却说不准新入口在哪里。住车站对面的邻居知道，可原稿上没有可以联系的人。画图的那位愿意把笔交出来，如今却要上夜班。一家旅店倒是请得起人重画，只关心怎样让自家的住客按时赶上早班车。这里人人都有一点有用的东西。一张能让下周的旅客也走到站台的图，要等哪些人碰上，要占去谁的星期天？

书名里的“开放”，可以先从这张图上认。你可以拿走副本，邻居可以纠错，旅店可以用它做生意，这已经是三种不同的自由。还有第四件容易忘掉的事。倘若大家都指望那位画图的人每周去看一眼，她有没有说过自己愿意？在通常所说的开放经济中，我们会关心商品、服务和资本怎样越过国界。本书也会跟着一只保温杯走过海关。我们还想把眼光留在一条街、一个班组或一个共享软件项目里，看看谁能加入，哪些成果可以带走，哪些责任有人接，代价又落在了边界哪一边。

因此，我们会花些时间才走到价格和货币。先得明白一件东西如何真正派上用场。坡道再平，入口锁了，推车的人还是赶不上车。钥匙找到了，又会有一个只有人才能回答的问题。拿钥匙的人愿意等到末班车吗？如果他已经答应了，别人据此买好了车票，他还可以怎样改约？等读到企业、市场与公共服务，我们再翻开账本。同样是掏钱，有人买了今天的一张图，有人付的是未来一年每逢改道都有人走一遍的工钱。光看金额，很难猜中旅客明年拿到的是什么。

你也可以先翻到自己最想问的地方。为什么美国几户人家还不上房贷，远处一家有订单的工厂会发愁周五的工资？机器人进了车间，为什么留在厂里的人和站在厂门口找第一份工作的人，会讲出不同的故事？到了书的末尾，我们还会试着给那张图找个长期的家。大家可以一起出钱，也可以让靠它经营的人从收入里拿出一份。究竟哪种办法更合适，要看下次改道时谁收到了消息、谁腾出了时间，以及那位推车的旅客最后走到了哪里。
