| 核查项 | 记录 |
|---|---|
| 主张与地位 | 文献实验结果。优秀绒条工具在教学条件下的后继作品承载量损失较小。 |
| 来源及作用 | L235 Lucas等2020，Methods、Results及图1、2。相邻作品绩效与整链改善斜率是两个比较。 |

| 当前用法与复核 | 用于区分作品形态、相邻传承与整链改进。外推到职业技艺前需复核练习时间及工艺差异。 |

| 适用边界 | 基线100%指纸面完成，3.5%指作者报告的现场完整执行。约63%是新版推出后首次整体观察。 |
| 已查与未知 | 已核原文所列百分比。每轮例数与3.5%的关系不足以反推整数例数，各项改动的独立效果和患者结局未知。 |

## 何时谈选择，何时谈积累（C7）

| 核查项 | 记录 |
|---|---|
| 主张与地位 | 两项文献论述。生物自然选择要求识别差异及其跨代延续。文化积累采用一项要求反复传递并改进绩效的定义提案。 |
| 来源及作用 | L229 Lewontin1970印刷第1页提供选择条件和细菌例。L230 Mesoudi与Thornton2018 PDF2–3、6提出四项核心条件并讨论绩效口径。 |
| 反向材料 | 条件外例。养分充足仍可发生差异繁殖。社会学习可以延续做法，也可以传播误差。 |
| 适用边界 | 生物世代按亲子对待，传递链的“代”按学习者位置对待。文化任务绩效须指明对象、期限与指标。 |
| 已查与未知 | 已查概念原段。各类组织能否辨认相应后继关系、怎样跨任务比较改善，仍有待验证。 |
| 当前用法与复核 | 将选择条件和积累判据放在案例之后。若换用其他积累定义，须重审正文有关改进的表述。 |

## 竞争与合作怎样共同进入一次继任（C8）

| 核查项 | 记录 |
|---|---|
| 主张与地位 | 有日期的事件事实，加项目条件推论。候选人竞争席位，选举与后续行权依赖共同规则，保留、采用和行权可分别检查。 |
| 来源及作用 | L234的PEP 13历史、8016接受记录、8100选举结果、602提案及2019年10月30日接受公告，各记录不同环节。L230 PDF6提出贡献与复制回报问题。 |
| 反向材料 | 角色替代解释。原任者进入新理事会。文书能定位正式决定，非正式影响力可能延续。分配情境属正文假设例。 |
| 适用边界 | 单一项目、首届选举及一次公开决定。五件文书组成同一事件链。 |
| 已查与未知 | 已核96名合资格者、69张选票与代表理事会的有条件接受。决策速度、长期维护工时与未入选者的待遇未知。 |
| 当前用法与复核 | 用于分清共同程序与竞争对象。评价制度优劣和回报效果时需参与者记录、成本和可比安排。 |

## 何时交换成果（C9）

| 核查项 | 记录 |
|---|---|
| 主张与地位 | 文献实验结果。有限接触在指定任务里保留了后来可重组的路径。跨任务的探索与交换安排属待验证假说。 |
| 来源及作用 | L231 Derex与Boyd2016，Results、Discussion及Treatments。按六人群体比较，两条件分母各12。 |
| 反向材料 | 作者的任务限制。完全连接早期有优势，实验预设互补路径。面板记录技能成果，未设置真实遗忘或产权处理。 |
| 适用边界 | 7／12与0／12分别指同时得到两条所需路径的群体。奖励按个人成绩，连接方式为操纵变量。 |
| 已查与未知 | 核过分母、路径和接触安排。竞争动机、合作回报及最优开放度的独立效应未知。 |
| 当前用法与复核 | 用于展示何时分享会影响可供选择的变体。推广前需比较无重组收益的任务及长期维护成本。 |
