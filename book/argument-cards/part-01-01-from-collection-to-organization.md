# 《从集合到组织》章节论证卡

第一部分第1章从一个指定性质进入组织判据。以下八组主张均由本项目研究助手于2026年11月13日整理。后两项分别保留探索性再分析与尚待操纵的机制。书中关于任务表现的判断以实验指定的目标为前提，使用者的利益、权利与成本需要另外评价。[章节讨论稿](../part-01/01-from-collection-to-organization.md) · [六项核查格式](../../shared/source-check-format.md) · [章稿用源记录](../../wiki/raw/round-58/README.md)

## 独立意见怎样汇总会改变比较基准

| 核查项 | 记录 |
|---|---|
| 主张与地位 | 项目再分析及条件推论。在正交视角下，从两人的判断中各取本视角的左右分量比取中点得到更小的独立汇总误差估计，可以解释为何观察到双人相对单视角个体的优势。 |
| 来源及作用 | L240的[补充工作簿S2](../../wiki/raw/round-55/L240-wisdom-dyads/mmc2.xlsx)提供独立落点及联合结果。第56批[配对清单](../../wiki/raw/round-56/trial-pairing.tsv)与[比较结果](../../wiki/raw/round-56/comparison-results.json)提供本项目的汇总估计。 |
| 反向材料 | 匹配限制及敏感性。2,560条联合记录均未形成同搭档、同视角、同目标的两个独立终点加一个联合终点。实验2的近邻半径由6.4放宽到12.8毫米时，真实配合与分量规则的次序改变。 |
| 适用边界 | 正交视角，成员误差可在同一块的目标间迁移并可独立取样，按搭档等权。分量规则和中点规则均由[第61轮比较协议](../../research/surveys/01-organization-maintenance/relational-organization-and-boundaries/dyad-comparison-protocol.md)预先固定。 |
| 已查与未知 | 已核两项实验“真实／中点／分量”依次为7.95／20.57／7.48和13.25／28.21／10.19毫米。未识别参与者实际汇总规则或两机制的收益比例。 |
| 当前用法与复核 | 将固定分工作为可检验的解释。取得同目标独立作答和实时配合的记录后，以直接配对替代跨目标估算。 |

| 适用边界 | 20对搭档、八个目标、双方都有动作才取平均输入，限时达到并停留。独立时各人自己操纵的光标可见，17.16%只度量隐藏的共同光标。 |

## 动作相反与有益纠偏之间

| 核查项 | 记录 |
|---|---|
| 主张与地位 | 项目探索性时序结果。对甲乙方向对称平均，用同目标同阶段的其他重复作对照，在约201和299毫秒间隔，共控相对独立的横向反向输入关联更强。 |
| 来源及作用 | L243同一批行为档案。[时序方法、三组间隔和结果](../../research/surveys/01-organization-maintenance/relational-organization-and-boundaries/live-control-and-replay.md#动作时序给了什么新信息)与[逐对计算](../../wiki/raw/round-57/painter-comparison.json)用于定位一段可能的作用过程。 |
| 反向材料 | 识别限制。97毫秒的差异接近零。约201毫秒时，另一项“输入指回目标线”指标在共控中并未更大。换用另一试次的动作还改变了当时两人共同看见的误差。 |
| 适用边界 | 移动提示后四个取样时点、指定帧间隔和横向投影，未作多重比较校正。动作对称计入，不指定领导者或神经反应起点。 |
| 已查与未知 | 已查时窗、错配规则、配对结果及方向检查。尚未操纵对方能否响应。C6和C7是同一实验的两种比较。 |
| 当前用法与复核 | 用于提出进一步对照。取得单方私有扰动或可见回放后，结合误差恢复重新检验“反向动作是在纠偏”。 |

## 回放留下的视觉任务假说

| 核查项 | 记录 |
|---|---|
| 主张与地位 | 两层说法。L242在触觉任务中报告真人连接与轨迹回放的效果不同。将“保留搭档回应能加快误差恢复”用于本章视觉任务，是待验证假说。 |
| 来源及作用 | L242 Ganesh等2014[全文](../../wiki/raw/round-57/L242-ganesh/article.jats.xml)表1、图2及两类回放方法，提供真实的对照先例。视觉任务的三条件设计与判据来自[本项目实验方案](../../research/surveys/01-organization-maintenance/relational-organization-and-boundaries/live-control-and-replay.md#还差的最小实验)。 |
| 反向材料 | 条件限制。较准者留下的轨迹也会帮助操作的人，较差者的轨迹可能使表现下降。直接重放力与将手柄连到预录轨迹的力学条件不同。 |
| 适用边界 | 原研究的实时和回放分属不同受试组，机械手柄与各自的光标有别于单一共享视觉光标。 |
| 已查与未知 | 已查原文与补充图，未取得可独立匹配的触觉逐帧数据。本章所需的同搭档视觉三条件实验尚未执行。 |
| 当前用法与复核 | 保留为可被削弱的假说。若实时组和可见回放组在同任务上的差值精确且很小，将解释收窄到共同反馈及输入规则。 |
