# 竞争、合作与共同能力的章节论证卡

日期：2026年11月12日。位置：第三部分第1章。状态：讨论稿。对应[正文](../part-03/01-cooperation-and-common-capabilities.md)。

## 问题与主张

将个体目标接到共同能力，联合研究竞争与合作怎样形成、维持和选择组织关系；区分共同收益、激励、形成、持续和群体整合。比较双方时指定任务、层级、规则和期间。

| 主张 | 地位 | 条件与依据 |
|---|---|---|
| 合作 竞争 共同意向与生物整合判据不同 | 工作区分及领域框架 | L51、L56、L57；适合度、金钱及道德评价不得直接换算 |
| 两类互动都参与组织关系的形成和改变 | 机制研究框架 | 不新增公设，不以行为一致或胜出证明通用Ordo增加 |
| 特定组间竞争处理的组内平均选择高于对照 | 有限经验结果 | L181实际选读1–7页；无独立复算，不推广到一般社会福利 |
| 共享基础并保留方案竞争改善持续改进 | 待验证领域假说 | 同任务比较质量、接口成本、回流和维护；允许失败及替代机制 |
| 共同收益、参与和规则实施不能合成一个条件 | 分析区分及有限经验支持 | L182定向选读PDF2–4、6、20；未唯一识别拒绝动机，未解决现实执行者形成 |
| δ≥c/b可支持所设触发策略的合作 | 条件性教学推导 | b>c>0、无限期折扣、完美观察、无执行错误；非唯一均衡 |
| 合作必然成为更高层组织 | 撤回普遍形式 | 合作群体形成与进一步整合需要不同证据 |
| 回报 角色知识和冲突处理影响合作维持 | 待验证假说 | 逐项比较，不能把共同变化全归因于意愿 |
| 生物整合可以要求社会成员放弃独立判断 | 不采用 | 描述生物机制不直接提供社会规范 |
