# 竞争、合作与共同能力

两位学习者可能互相帮助完成课程，也可能竞争同一场展示机会。在不同任务和时间范围内，同一对人可以既合作又竞争。解释他们的关系，需要指出谁采取了什么行动、影响谁、与什么情形比较，而不能先把整个人归为合作者或竞争者。

## 竞争与合作共同作为需要解释的现象

合作应当进入组织形成的主线。分散参与者怎样取得共同能力，怎样分担投入，以及这种关系为何继续，是通用组织理论在人类领域的重要问题。

不同领域对合作有不同的判据。演化生物学需要说明性状怎样影响相关实体的适合度及其形成历史；共同任务研究可以描述投入、策略与结果；共同意向研究还涉及参与者怎样理解彼此的行动和角色。不能把一种领域的受益直接换成另一领域的金钱，也不能从观察到的贡献唯一判定动机。[^evolution]

合作与竞争都需要具体机制。自然选择中的差异繁殖，不等于所有互动都在直接对抗；观察到合作，也不意味着选择、利益分歧或冲突已经消失。比较何者更重要，应先指定现象，而不是为所有层次排一个固定次序。

在人类共同任务中，本书以相互配合、互补投入或共同维护识别合作性活动，再分别检查共同意向、实际受益和自愿程度；以争取稀缺或不相容的机会、资源、收益或选择结果识别竞争。两者不是对人的永久分类，也不要求一方增加时另一方必等量减少。

甲乙可以共同准备课程，争取不同的演示方案，又就展示时间发生分歧；另两位学习者可以与他们竞争展示机会，同时使用和维护共同资料。要解释这些关系，至少指定任务、层级、规则和期间，不能仅凭他们是否互相喜欢判断。

## 两种互动怎样改变组织的秩

竞争与合作共同进入本书的Ordo路线，因为它们会改变关系怎样形成、维持、被选择和重组。合作可以建立分工、接口与共同基础，竞争可以改变方案采用与资源流向；二者都可能支持能力，也可能破坏维护、压制替代或把损失转给别人。

这里的联系首先是机制问题。哪些关系改变了？在同样任务和资源下，质量、可靠性、学习、维护和适应发生了什么变化？本书还没有通用Ordo标量，不能只用“合作更多”或“竞争更强”断言总体增秩，更不能以整齐和服从代替组织能力。

一个联盟内部配合很好，却可能共同排斥外人；一场竞争可以发现更好的方案，也可能只奖励操纵评分的能力。因此内部凝聚、竞争胜出、任务效果和全部受影响者的处境，要分别判断。规则的作用不只是限制竞争，也包括使共同维护、争议处理与改选方案能够继续。

已有实验也提供了同时研究两者的入口：在特定最低努力协调博弈中，组间竞争处理的组内平均选择高于对照。这个结果不能直接推广为竞争必有益，更不是测得了Ordo；它提醒我们，把竞争和合作拆成互不相干的主题，会遗漏层级之间的联系。[^joint]

## 共同收益怎样到达投入者

甲准备材料、乙制作演示，可能比各自重做全部内容更有效。但共同收益存在，尚不保证两人愿意承担各自的投入，也不保证他们有条件履行。

Nowak对亲缘、直接互惠、间接互惠、网络和群体选择的整理，提供了寻找合作机制的地图。各机制有自己的关系结构和变化规则，不能合并成共同收益越大、合作就必然出现的定律。[^mechanisms]

一个有限的重复互动模型展示了这种区别。设每期帮助成本为c、给对方的收益为b，且b>c>0；互动无限延续，未来折扣为δ，行动完全可观察且没有执行错误。双方约定先合作，一旦有人背叛便永久停止合作。在这个模型中，比较继续合作与当前偏离的价值，可以得到δ≥c/b的合作支持条件。[^model]

这个条件只说明所设安排能够成为一种均衡，不保证参与者会学会或选中它；永远不合作的均衡仍可能存在。已知终期、错误、宽恕或伙伴选择改变时，需要重新分析。模型中的δ也不是道德水平或熵秩分数。

因此，共同活动是否可行、参与是否有利、安排能否执行、策略如何形成，以及长期能否维持，要分别研究。

## 形成规则也需要共同投入

即使同意共同生产，人们也可能希望别人先承担核验、协调和执行规则的成本。制度形成的实验把参加、实施和公共品投入分成不同阶段，并观察到一些改善参与者物质所得的子群体安排仍被拒绝。共同收益与规则接受不能合为一个条件；这一结果也不足以唯一识别拒绝者的动机。[^formation]

规则本身还需要可靠的执行能力。模型里设定某项制裁有效，并不等于已经解释现实中谁来执行、怎样付款、如何纠错与接替。下一章研究共同承诺时，要把这些支持条件一起带入。

## 从合作群体到组织整合

分工、协调和相互依赖可以形成新的能力，但合作群体不自动成为新的生物个体。West等在重大个体性转变的讨论中，区分合作群体形成与进一步整合，明确要求继续解释内部冲突和群体共同表现。[^evolution]

人体的组织整合与公司的协调，不能直接使用同一个判据。人还可能同时属于多个群体，改变角色或离开某项关系。一般组织研究需要识别关系的作用，不要求所有成员形成唯一共同目标，更不能以生物整合为理由要求个人失去独立判断。

生物演化、个体学习与文化制度变化也应分别建模。它们改变和传递的对象不同：一次学习并不等于遗传变化，制度延续也不自动证明它最有效或最正当。

## 共同活动怎样进入人的理解

两人使用同一材料，可能只是各自行动；也可能理解自己在参与同一项任务，知道怎样配合彼此的角色。共同意向的研究为这种区别提供了认知与发展方向，尚未解释全部人类合作。[^intentions]

本书保留一个待验证假说：在具有先后依赖的任务中，收益与回报路径、角色知识和冲突处理共同影响合作的持续。要检验它，需分别改变这些条件，记录质量、投入、维护与退出，避免把同时变化的结果全部归因于合作意愿。

另一项需要检验的安排是：共同维护基础材料，允许不同团队竞争实现与服务。它是否更好，要与具体替代方案比较接口、重复投入、质量、回流与维护，而不是预先宣布“合作为主”就必然优越。后续组织比较与经济章节将继续追问：哪些环节需要共同承诺，哪些环节适合保留竞争，收益和责任怎样连接？

即使合作已经形成，目标仍可能改变，参与者也会面对新的机会。[下一章](02-revisable-shared-commitments.md)追问：怎样使这些可以改变的人，形成他人能够依赖的承诺？

## 本章论证地位

| 表述 | 地位与范围 |
|---|---|
| 合作 竞争 共同意向与群体整合分别研究 | 工作区分及文献框架，领域判据不可直接互换 |
| 竞争与合作共同改变组织关系 | 机制研究框架；每次说明任务、层级、规则与期间，不设固定正负效应 |
| 特定组间竞争下观察到较高组内平均选择 | 有限实验结果；所读设计与部分结果不代表社会整体或通用Ordo |
| 共享基础并保留方案竞争更利于持续改进 | 待验证的领域假说，接口、回流、选择标准和维护可能使其失败 |
| 特定触发策略下δ≥c/b可支持合作 | 继承博弈思路的条件推导，前提包括无限期、完美观察及无错误 |
| 合作必然产生更高层组织 | 不采用其普遍形式；形成与整合需要分别解释 |
| 回报 角色知识与冲突处理影响持续合作 | 待验证机制假说，不是已经成立的充分条件 |
| 共同收益与规则接受分别解释 | 有限模型及实验支持的区分；拒绝动机不能唯一识别，现实执行者的形成仍需研究 |
| 合作结果是否值得支持 | 价值问题，需计入外部受影响者，不能用内部配合程度决定 |
