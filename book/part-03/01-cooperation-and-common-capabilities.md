# 合作与共同能力

两张贴纸放在两个小盒里，面前露着一个绳头。拉一把，贴纸就是你的了？在法国一间学校里，真这么做的孩子会发现，绳子倒是很听话，整根都被抽过来了。盒子还在原处。[^rope]

原来两个绳头属于同一根绳，中间只是绕过了装置。两端隔得够远，一个孩子没法同时握住。要把盒子拉近，得等另一头的小朋友也握好，一起往回拉。还有个容易忽略的关口。你已经拿到自己的贴纸了，现在能松手吗？搭档也许正伸出手去。早松一下，两个人忙活半天，只有一个人拿到贴纸，这一轮仍算没有共同完成。[^rope]

研究者在15所学校让145对孩子试了试。第一次，两个人都拿到贴纸的有91对；还有31对到第二次才成功，9对到第三次才成功，最后14对试了三次也没能一起拿到。老师希望大家最后都有贴纸，于是实验结束时，研究者把贴纸发给了孩子。要是等到放学再清点谁手里有贴纸，这场实验最有意思的东西就看不见了。[^rope]

[上一章](../part-02/04-goal-conflict-and-revision.md)里，那位搭档准备了两套工具，等着有人来。现在可以把问题再推一步了。第二个人来了，究竟多出了什么？在绳子的两端，答案很清楚。多了一双在另一处够得着的手，也多了一件得靠双方安排好的事：谁什么时候开始拉，什么时候才松手。换成两个人都能独自完成的任务，答案就没这么容易了。

## 楼梯究竟有多少级？

布宜诺斯艾利斯的方尖碑里面有楼梯。没去数过的人，不妨先猜一个数。阿根廷一项实验真的出了这道题。有一组四个人先各自写下300、80、200、40。假如现在收卷，替他们取个平均，交上去的是155。研究者给了他们讨论的机会，小组交上去的是220。正确答案是206。讨论让误差从51级缩到14级。可那张写着200的纸，原先只差6级。[^stairs]

所以，这组讨论得好不好？如果你事先得定一个交卷办法，取平均是人人会用的规则。讨论在这一题上胜过了它。如果你想知道四个人有没有想到任何一个人原先都没想到的更好答案，同一组的成绩就得另说了。尤其不能在知道答案以后把那张200挑出来，再假定开会以前就知道该听谁的。

我们把作者公开的个人答案与小组答案逐题配回去，在通过原研究筛选、且能找齐四份初答并核对平均数的294个组题中，讨论结果有216次比四人的平均更准；跟当题猜得最准的那个人比，讨论更准的有94次。这里数的是小组做题的次数，同一组会做几道题。那94次说明，桌上确实会出现一个比原来四张纸都好的答案。它们还不能告诉我们，把时间再给个人几分钟，他是否也能想出来。[^stairs]

研究者还把这几分钟专门拿出来比。大家都接到同样的指点：遇到估不出的量，拆成几个估得出的量。猜楼梯，可以先猜相当于几层楼，再估每层多少级。实验里一半人独自写出推算，另一半分成四人组一起想。等讨论窗关掉，每个人又得自己交卷。经历小组讨论的人，最后个人估算的误差平均更小。到这里，比较才把“多想一会儿”和“跟别人一起想一会儿”分得更开。至于上面那组人究竟怎样谈出220，光看五个数字可听不见他们的谈话。[^stairs]

讨论也有早了的时候。另一项双人实验围绕相同的主题换了个问法。问费城有多少人没有医疗保险，回答人数时，多添一个零就可能差出很远；问这占人口的百分之几，答案天然落在0到100之间。先各写下自己的估计，再讨论，在容易猜错数量级的题上胜过简单平均。在百分比题上，这个优势没有显现；如果从第一句话起就一起想，两个人考虑的范围反而更窄，表现还落在先各自作答再平均的基准之后。有时合作值得保留的第一步，恰好是给每个人一张自己的草稿纸。[^dyads]

## 谁先说出嫌疑人

如果四个人都乐于把自己知道的东西摊在桌上，已经省去了一道难题。换一种玩法，看看桌上的材料还剩多少。

在一项虚构的交通事故调查里，三位参与者各有一份案卷。19条材料人人都有，另有9条关键线索分散在三人手里，每人独有3条。他们先独立判断嫌疑人，再坐到一张桌前，可以随时翻手中的材料。一些小组接到的任务是共同找出肇事者；另一些小组要争当组里第一个提出最佳答案的人。没有奖金，案子也没有换。[^clues]

录像留下了讨论经过。共同破案时，成员更常把别人没看过的线索说出来，也更常提出与自己最初判断相抵触的理由。讨论结束后，每个人都单独交了答案。每种规则各有15个三人组，按“三个人都答对”来算，共同破案的一边是93%，争先的一边是33%。如果只问“至少有一个人答对”，两边变成93%和60%。一个团队里有人知道，与每个需要据此行动的人都判断正确，中间还隔着一次传递。[^clues]

独自看案卷的人当然也可能猜中。想象另编两个案子，你手上那一页逐字相同，唯一能分辨它们的证词在搭档手里，而两案的肇事者不同。你若只能按自己这一页作答，无论多仔细，总会在一个案子上答错。搭档把证词念出来，才有根据把两案分开。这里多出的能力，是在情况改变时也能辨别，不只是某天走运猜中了。

问题还在于证词有没有机会被念出来。按争先规则，一个人示意要交答案，讨论就停下。按共同规则，要等小组宣布决定。实验照出了整套安排造成的差别，没有读出哪个人心里藏着线索，也没把抢答和提前结束各占多少分开。把它搬回课程演示，倘若最先报出故障的人能得分，手里握有反例、还需一分钟核实的搭档，有没有机会说完？

## 篮筐只有一个

现在把争胜挪到队与队之间。56名男性参加了一项三分钟的投篮实验。一个人练，自己投、自己捡，把球给研究者，等四秒，再投。组成两人队以后，也要自己捡球，不过这回是把球传给等在投篮点的搭档。两人先前的个人成绩加起来，成了他们可以一起去打破的纪录。[^hoop]

还可以跟另一队比。两队轮流上场时，一队先投，另一队在旁看，先投一队的分数会公布。也可以让两队同时开球，各有一个球，各站一边，却朝同一个篮筐投。两种比赛里，捡球的人都得把球好好传给队友，对面那一队也都想赢。[^hoop]

研究者按每一投的质量计分，从投空到空心入篮给零到五分，累计每个人三分钟的总分。独投平均53.16分，两人结队挑战旧纪录53.29分。两队分时上场比总分，升到了58.62分；让两队同时对着同一篮筐投，是51.20分。分时竞争的得分高于其余三种，另三种在这项指标上的差异没有达到统计显著。若只数球进筐几次，结队挑战旧纪录和两队同时比赛，又都多于独投。两球同场时究竟是分神、等球，还是别的变化起作用，单靠这个设计拆不开。[^hoop]

所以，说“竞争提高了成绩”，还差好几个词。谁跟谁比？共用哪种资源？投得更快、球进得更多，还是每一投更准？同一位球员把球传稳，是在帮搭档，也是为了胜过另一队。竞争放在哪一层，会改变合作所处的条件。前面查案时，抢先交卷会截断队友的发言；在这里，两队比总分还能给传球的人一个把球传好的理由。至于这种配合对场外的人有何好处，记分牌一句也没说。另一项组间协调实验也发现，在特定规则下，组与组竞争时，组内成员选择的努力水平平均更高。[^joint]

## 第二个人下周还来吗？

绳子、楼梯和篮筐把组织的“秩”这个大词带回了手边。绳端的动作能否同时发生，独有的线索有没有传到需要它的人手里，错误判断能不能被推翻，都可以观察。队员口径一致也许说明他们已经交换了关键线索，也可能说明第一个开口的人说完，大家就散会了。要用Ordo解释组织能力，还得检查具体关系让什么成为可能，花了什么代价，谁失去了机会。一个普遍适用的Ordo分数，不能从这几场实验里读出来。

这里说的合作，是人在某件事上相互配合、提供互补投入，或共同维护完成任务的条件。竞争发生在他们争取不能同时归各方的机会、份额或位置时。两者都要指明任务、对象和时段。生物学讨论合作演化，用的是适合度和传递条件；一对孩子双双拿到贴纸，还不能由此识别他们是否自愿、有共同意图，或愿意明天再来。亲缘、直接与间接互惠、网络或群体选择各有成立条件。一群能暂时配合的个体怎样进一步整合、内部冲突怎样处理，也仍须另行解释。[^mechanisms][^evolution][^intentions]

再想想那位每周带工具来的搭档。假定两人每次帮助对方，自己付出成本 *c*，对方得到收益 *b*，其中 *b > c > 0*。未来可以一直往来，下一期的收益按 *δ* 打折（*0 ≤ δ < 1*）。如果两人都能准确看见对方是否出力，又都准备在对方第一次失约后永远停止互助，那么今天少帮一次，眼前省下 *c*，以后每期却会失去原本能得到的净收益 *b − c*。在这些很强的假定下，当 *δ ≥ c/b*，继续帮忙可以成为双方都愿意维持的选择。从一开始谁也不帮谁，同样可能维持下去。漏看了一次交接，或者照护突变被误认成失约，这套算术的前提就变了。[^model]

能一起做好一件事，与愿意承担下一次的投入，毕竟要看两次。连制定和执行规则本身也要有人出力；在一项公共品实验里，一些能改善参与人物质所得的制度安排仍被拒绝。我们还想检验，先留一份人人可用、有人维护的材料，再让各队拿不同的修理方案去比，能否少些重复劳动，又保留试错的余地。得把省下多少工、修复质量、有无遗漏、谁愿意继续维护都记下来。决定让谁分得收益、谁能对规则提出异议，还需要当事人给出理由。[^formation]

这一周，两个人果然把信号器修好了。下周轮到搭档做演示，他得知道，在自己动身以前，另一位能不能把图纸送来，临时有变又到哪里找人。这才有了下一章的问题：[一项共同承诺怎样既可依赖，又容得下修订？](02-revisable-shared-commitments.md)

## 本章论证地位

| 表述 | 地位与范围 |
|---|---|
| 在允许的动作和器材下，一人够不到必须同时操作的两个位置；双人可到位仍会失败 | 前半为可行性条件推论，后半为拉绳首试的文献观察 |
| 讨论有时优于同题独立平均，也有时丢掉最好的初答 | 估算实验及本书对完整组题的描述性复核。误差改善与个人办不到分别取证 |
| 团队首答、分别上场争胜、同时共用场地会改变配合的结果 | 有限定的实验比较。停止规则、资源和评判指标随安排而变 |
| 合作 竞争 共同意向与群体整合分别研究 | 工作区分及文献框架，领域判据不可直接互换 |
| 竞争与合作共同改变组织关系 | 机制研究框架；每次说明任务、层级、规则与期间，不设固定正负效应 |
| 特定组间竞争下观察到较高组内平均选择 | 有限实验结果；所读设计与部分结果不代表社会整体或通用Ordo |
| 共享基础并保留方案竞争更利于持续改进 | 待验证的领域假说，接口、回流、选择标准和维护可能使其失败 |
| 特定触发策略下δ≥c/b可支持合作 | 继承博弈思路的条件推导，前提包括无限期、完美观察及无错误 |
| 合作必然产生更高层组织 | 不采用其普遍形式；形成与整合需要分别解释 |
| 回报 角色知识与冲突处理影响持续合作 | 待验证机制假说，不是已经成立的充分条件 |
| 共同收益与规则接受分别解释 | 有限模型及实验支持的区分；拒绝动机不能唯一识别，现实执行者的形成仍需研究 |
| 合作结果是否值得支持 | 价值问题，需计入外部受影响者，不能用内部配合程度决定 |
