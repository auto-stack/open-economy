# 主张与来源的轻量核查格式

版本0.1，2026年11月13日。供书稿论证卡和研究笔记随主张维护；每次只填实际采用的主张，不批量建立空卡。它帮助留下判断依据，不是评分表，也不自动证明主张正确。

## 六项记录

| 项目 | 最少写什么 |
|---|---|
| 主张与地位 | 一句可检查的主张；文献结果、条件推论、假说或价值主张；将用于哪里 |
| 来源及作用 | 谁在说、哪一版、哪个原件／页段；它支持、定义、推导、提出动机、更正、质疑还是回应什么 |
| 反向材料 | 谁针对哪一层提出什么问题，有无回应；注明类型及是否实际读过，尚未查找也写明 |
| 适用边界 | 对象、任务、时间、单位和关键条件；哪些推广不成立或尚未检验 |
| 已查与未知 | 实际读段、原件状态、是否复算；缺什么证据或争议哪部分仍未裁决 |
| 当前用法与复核 | 可有限采用、保留争议或尚未验证；下一次什么新资料会触发复核；记录人和日期 |

一份文件含目标论文、评论和作者答复时，应分开说话者与文段身份；几份更正、复核和答复争论不同结果时，应分开主张。相同文件或共享数据不能计成多份独立经验支持。

## 类型不要混用

反向材料可注明：作者更正、结果复核分歧、识别／方法异议、替代解释、适用范围限制、条件外例子。**尚无验证是证据缺口，未找到反向材料不等于不存在反证。** 质疑存在不自动推翻全部结果，作者回应也不自动结束争议。

官方网页可能同时保留原摘要与更正入口；仅记网址或访问日期不够，应注明实际采用的主张版本。未读的论文、评论或代码标为待查，不能用搜索摘要或回应方的概述代替对方原文。

## 可直接随卡填写

> 主张／地位／用途：……  
> 来源／作用／版本及读段：……  
> 反向材料／针对对象／回应状态：……  
> 适用边界：……  
> 已查／未知：……  
> 当前用法／复核触发／记录人及日期：……

没有已知争议时仍说明反向材料查到什么程度；主张复杂时按实质结果拆开，不把整篇论文盖一个“有效／无效”章。原件与文件校验可放在归档记录，不必反复复制进每张卡。

两个已填写的试用见[来源争议案例](../research/surveys/06-technological-levers-and-organizational-evolution/explanations-memory-and-revision/disputed-sources-2026-11-13/README.md)。格式是否减轻实际维护负担仍待观察，不由填写完整直接推断检索或合作效率提高。
