# 开放经济学定义 公设与命题总表

版本：0.2 工作稿。日期：2026年11月12日。

本表统一 Q1–Q8 的当前口径，供[纲领](../docs/charter.md)、书籍与论文引用。各轮原稿保留当时状态；本表的工作采用不表示定义唯一，也不把模型核算升级为现实规律。综合判断和旧命题处理见[首轮综合](../research/reviews/10-research-synthesis.md)。

## 分类与状态

| 编号前缀 | 地位 | 使用要求 |
|---|---|---|
| DEF | 工作定义 | 划定讨论对象，不凭定义证明某种能力存在 |
| AX | 基本公设或基础承诺 | 明确采用范围；当前只有物理实现这一继承性承诺，没有新增普遍群体行为公设 |
| BASE | 继承的数学或物理结果 | 保留原有条件，不称作本项目新发现 |
| ASS | 领域及模型假设 | 在具体模型中选择，检验其映射、参数与敏感性 |
| PROP | 已推导或核算的条件性命题 | 区分解析推导、有限枚举、数值结果、反例及账户恒等式；不自动获得经验支持 |
| HYP | 待验证假说 | 给出可观察结果、替代解释与失败条件 |
| NORM | 制度目标或评价选择 | 说明价值及取舍，不冒充物理推论 |
| PAR | 应用或示例参数 | 区分候选规则、待测参数和纯演示数值 |
| DES | 候选制度设计 | 尚需检验预算、参与、执行及治理，不代表已实施 |

“已核算”只适用于写明的模型。“工作采用”用于本阶段统一语言；“待验证”指现实假设、跨系统推广或设计效果尚待检验。文献中有限的经验结果仍在原阅读笔记中记录，本表没有据此建立通用经验定律。

## 工作定义

以下 DEF 条目作为0.2版工作约定采用。解释力与识别的可重复性仍需案例检验。

| 编号 | 概念 | 统一口径及边界 | 依据 |
|---|---|---|---|
| DEF-01 | 分析描述与边界 | 声明组成分解、关系、状态、环境、尺度、期限及研究性质；涉及比较时再声明对照、精度与预算。边界须有问题和机制理由，不预设唯一划分 | [Q1 判据](../research/reviews/02-organization-criteria.md) |
| DEF-02 | 有组织性与组织单元 | 相对于 DEF-01 的描述，关系与约束安排对目标性质或过程有可辨认、可解释的作用；组织单元是为解释这些作用选定的部分及关系。集合与组织不作为永久互斥的物体类别 | [Q1](../research/reviews/02-organization-criteria.md) |
| DEF-03 | 持续性与稳定性 | 持续性描述指定结构或活动在期间内保持；稳定性是相对于状态、轨迹、集合及扰动的动力学性质。持续、恢复、财务偿付与行为均衡分别判断 | [Q1 比较](../research/reviews/01-findings.md)、[Q6](../research/reviews/07-economic-bridge.md) |
| DEF-04 | 调节 | 减小扰动对指定变量或任务结果的影响；不包含调节器自身得到修复或生产 | [Q2](../research/reviews/03-self-maintenance.md) |
| DEF-05 | 维护与自维持 | 维护贡献是系统活动对列明构成条件的维持具有可识别的因果作用；范围限定的自维持还要求相关维护关系在给定资源、时间与扰动范围内支持声明的组织条件，外部承担部分须写明 | [Q2](../research/reviews/03-self-maintenance.md) |
| DEF-06 | 适应能力 | 在指定可维持或可生存条件及变化趋势下调整活动的能力；借鉴生命组织的判据时保留其条件，进入社会领域须另定义对象和结果，不由持续或增长推出 | [第一轮](../research/reviews/01-findings.md)、[Q2](../research/reviews/03-self-maintenance.md) |
| DEF-07 | 任务能力与功能 | 在指定任务、环境、可行动作、资源及期限下的表现，可用成功率、误差、吞吐、恢复时间等多维量描述；评价者指定任务不等于系统具有共同目的 | [Q3](../research/reviews/04-measures-and-bridges.md) |
| DEF-08 | 熵 信息与复杂性 | 热力学熵、Shannon熵、互信息、熵率、预测状态复杂性和任务能力分别命名；单位、变量、概率及参照随量记录。“信息量”不直接指字节数、正确性或经济价值 | [Q3](../research/reviews/04-measures-and-bridges.md) |
| DEF-09 | 模块 | 分别识别结构、动力学、功能与设计模块；划分依赖关系语义、任务、时间、误差或设计责任，四种模块不必重合 | [Q4](../research/reviews/05-modules-interfaces-hierarchy.md) |
| DEF-10 | 接口与封装 | 接口是相互作用中外部可依赖的变量、行为和约束；封装是在限定内部变化与调用任务下保持外部约定的安排。存在接口不保证独立、零成本或无需维护 | [Q4](../research/reviews/05-modules-interfaces-hierarchy.md) |
| DEF-11 | 粗粒化 | 将细状态映射为粗描述；应说明丢失信息、预测闭合与精度。它是描述变换，不自动等于系统实际建立接口 | [Q4](../research/reviews/05-modularity-models.md) |
| DEF-12 | 层级 | 在同一种声明关系上的多层安排，例如组成、依赖或控制。嵌套组成不自动具有权威上下级，也不直接等同于对称破缺 | [Q4](../research/reviews/05-modules-interfaces-hierarchy.md) |
| DEF-13 | 记忆 预测与复用 | 记忆经机制保留过去影响；预测信息指向指定未来变量，预测器依记录作判断；复用把既有成果用于新任务实例。记录、显式内部模型、实际策略和净收益分别记录 | [Q5](../research/reviews/06-memory-prediction-reuse.md) |
| DEF-14 | 经济主体与制度 | 主体按决策权限、可选行动、信息和后果识别；制度是领域中实际起作用的规则、权利、承诺与执行安排。物理节点不自动都是有意主体，规则文本不自动代表履行 | [Q6](../research/reviews/07-economic-bridge.md) |
| DEF-15 | 公共成果及物品属性 | 分别记录排除难度、使用减损、拥挤及复制条件；公共品与会减损的公共池资源有别。代码、支持工时和服务器容量可属于不同成分 | [Q6](../research/reviews/07-economic-bridge.md) |
| DEF-16 | 成本 支付与资金 | 真实投入和机会成本、转移支付、现金可用性与预算分别核算。相同边界内转移支付不重复算社会损失，但会改变各方参与和偿付 | [Q6 模型](../research/reviews/07-economic-bridge-models.md)、[Q7](../research/reviews/08-open-funding.md) |
| DEF-17 | 回报 奖励与维护委托 | 分开劳动报酬、自用及参与收益、经营净额、风险回报与剩余分配；认可过去贡献的奖励不自动产生未来维护承诺 | [Q7](../research/reviews/08-open-funding.md)、[Q8](../research/reviews/09-autoos-open-business.md) |
| DEF-18 | 制度开放与 Open Business | 分别声明访问复用、经营接入、规则透明、接口兼容、治理和回报；Open Business 是将共同服务、经营及公共贡献支持连接的候选制度族，AutoOS为具体研究场景 | [Q8](../research/reviews/09-autoos-open-business.md) |

Ordo 保留研究名称，尚无工作采用的通用标量定义。不得以 DEF-08 或一组指标的并列记录代替其有效性证明，见 HYP-01。

## 基本公设与描述要求

**AX-01 物理实现。** 本研究讨论的具体组织、主体行动及制度运行均通过物理过程实现，服从与其对象和条件相符的物理规律。跨入生命或社会领域仍需给出机制映射。地位为继承性基础承诺，不是本项目证明的新定律，也不意味着所有领域变量均已由物理量唯一决定。[依据与范围](../docs/charter.md)

Q1–Q8 尚未给出可工作采用的、非定义性的普遍群体行为新公设。“所有组织主动自保”“必然增长”“普遍自利”“必然最大化熵产生”均未纳入。后续提出新的公设时，应证明它增加何种可检验约束，说明反例怎样处理。

组成与关系共同描述、声明边界、比较同一任务、给出反事实、注明单位及区分证据等级，属于 DEF-01 及研究方法要求。它们不另包装成几条自然定律。“有限资源”也应落实到具体预算及时间条件，不能只靠一句公设产生任意模型的成本函数。

## 继承的数学与物理结果

| 编号 | 可以采用的结果 | 关键条件及不能省略的部分 | 地位与依据 |
|---|---|---|---|
| BASE-01 | 同一离散物理状态及分布上，\(S_G=k_B\ln2\,H\) | 逻辑或宏观状态若隐藏内部自由度，需计内部熵；不是任意社会统计量的热力学等式 | 已有定义与换算；[Q3 §2.1](../research/reviews/04-measures-and-bridges.md) |
| BASE-02 | 固定有限状态、均匀参照下，\(D(p\Vert u)=\ln N-H_{nat}(p)\) | 指定状态空间及参照；其他熵差关系需相应约束，不能自动解释功能 | 已有概率恒等式；[Q3 §2.2](../research/reviews/04-measures-and-bridges.md) |
| BASE-03 | 给定能级、温度及正则参照，\(F[p]-F_{eq}=k_BT D(p\Vert p^{eq})\) | 相同模型下的自由能；非同能量分布不能省掉能量差，多热浴和其他稳态另建模 | 继承的条件性物理联系；[Q3 §2.3](../research/reviews/04-measures-and-bridges.md) |
| BASE-04 | 对称等概率二态存储器标准复位的理想平均排热下限 \(k_BT\ln2\) | 温度与复位条件明确，排向热浴为正；不是固定每bit每秒存储成本或普遍逻辑操作费 | 已有物理结果；[Q3 §2.4](../research/reviews/04-measures-and-bridges.md) |
| BASE-05 | 特定随机驱动物理模型中，记忆与预测信息之差与驱动步骤耗散相连 | 热浴、无反馈驱动、Markov响应及协议步骤条件；单步等式与完整协议界不同，不推出社会利润规律 | 文献条件性结果；[Q5 物理联系](../research/reviews/06-memory-prediction-reuse.md) |

守恒、热力学收支及动力学工具继续按其科学适用条件继承。本表列出的是首轮重点使用的连接，不是物理学公理的完整清单。

| ASS-02 | 稳定中间成果 | 独立中断只损失未保存段、检查点不失效且组合正确、给定保存开销。用于 PROP-05；[Q4 模型](../research/reviews/05-modularity-models.md) |
| ASS-03 | 固定耦合预算 | 对称四节点线性扩散、同容量、\(2a+4b=B\)。用于 PROP-06；权重不是直接的能源或资金成本 |
| ASS-04 | 环境与信息使用 | 二态平稳转移、信号可靠度、指定观测、允许解码和行动时点。分别用于 PROP-03、PROP-04、PROP-07；不能把不同例子的数据混为一套机制 |
| ASS-05 | 对数增长任务 | 比例分配、匹配回报和给定真实信号分布；收益按对数增长与相同基准比较。用于 PROP-08；[Q5 模型](../research/reviews/06-memory-reuse-models.md) |
| ASS-06 | 复用与共享错误 | 变化过程、无误验证、更新成功、兼容性及全周期成本给定；共同错误与独立错误对照保持边际错误率相同。用于 PROP-09、PROP-10，不把它们当作现实保证 |
| ASS-07 | 经济偏好与可选行动 | 准线性或其他明确效用、行动权限、信念、关心他人程度、外部选择和信息条件；完全自利和完全信息仅为部分例子的简化。用于 PROP-11、PROP-12 |
| ASS-08 | 隐藏努力合同 | 努力不可观察、结果可据以付酬、已知概率、风险中性、非负成功奖金和给定退出收益。用于 PROP-13，不是所有激励机制的假设 |
| ASS-09 | 条件筹资规则 | 固定参与者、全体必要、指定报价、退款与失败奖金，以及签约成本的不同版本。用于 PROP-14；普通纳什与文献的精炼均衡不能混用 |
| ASS-10 | 补充服务和资金账户 | 核心已可信融资时的增量服务需求、交付成本、回流份额与独立资金来源。用于 PROP-15；尚未解出融资与购买的联合均衡 |
| ASS-11 | 多期到账与储备 | 固定到期支出、外生随机到账、跨期独立、来源间相关结构、初始储备及无借款。用于 PROP-16；不代表实际赞助概率 |
| ASS-12 | AutoOS结算与分配场景 | 费用加收口径、净结算本金、退款政策、不可回收成本、指标可制造及有限池等。用于 PROP-17至PROP-20；均需与实际规则对应，[Q8 模型](../research/reviews/09-autoos-models.md) |

评价社会结果还需要 NORM 项；选择一种效用或均衡作描述不自动决定整体应该怎样评价。

| PROP-13 | 固定付款覆盖高努力成本，仍可不能激励高努力；成功奖金只在参与和激励区间重合时可行 | ASS-08；本例高努力成本4、成功概率0.9/0.4给出w≥8，支付者上界10−g/0.9；[Q6](../research/reviews/07-economic-bridge-models.md)。等号为弱激励，只针对该合同族 |
| PROP-14 | 在固定全体必要的报价例子中，失败奖金可使接受成为严格优势策略；足够签约成本会恢复不供给均衡 | ASS-09；8个行动组合及偏离枚举，[Q7](../research/reviews/08-open-funding-models.md)。不是任意众筹或不完全信息机制的保证 |
| PROP-15 | 营业收入、服务净额和实际回流维护的金额不同；转移支付与真实成本需分开 | DEF-16、ASS-10；账户恒等与预算条件，[Q6](../research/reviews/07-economic-bridge-models.md)、[Q7](../research/reviews/08-open-funding-models.md)。这不是新因果定律或企业愿意回流的证明 |
| PROP-16 | 相同期望收支不保证逐期履约；分散来源对中断风险的排序可随储备反转 | ASS-11；12期完整余额状态递推的有限数值结果，含零储备反例；[Q7](../research/reviews/08-open-funding-models.md)、[结果](../research/examples/open-funding-results.json)。不宣称普遍的风险单调律 |
| PROP-17 | AutoOS指定收费与回馈口径下，平台可用份额为\((1-\beta)\tau E\)，预算仍需覆盖平台自身成本 | ASS-12；账户分配与条件不等式，5%/50%例子只保留计费本金2.5%；[Q8](../research/reviews/09-autoos-models.md)。不证明候选费率实际足够 |
| PROP-18 | 已付款不可追回时，全额退款消耗的储备可能超过技术费；暂缓分款也不消除不可回收成本 | ASS-12的退款政策与现金流场景，逐笔守恒核算；[Q8](../research/reviews/09-autoos-models.md)。不是AutoOS当前责任或支付渠道政策的断言 |
| PROP-19 | 固定回馈池与真实小额收藏成本仍可容许有利的虚构权重，预算守恒不保证分配可靠 | ASS-12的直接乘积评分及可制造权重，有限反例；[Q8](../research/reviews/09-autoos-models.md)。没有实现攻击，也未证明某防护已解决问题 |
| PROP-20 | 上期支持、点赞或首轮表现不自动满足下一期保留及推广预算；有限池也不蕴含固定人均收入 | ASS-12、显式授权及固定池，预算反例与均值核算；[Q8](../research/reviews/09-autoos-models.md)。长期承诺及真实付款行为仍需单独机制 |

## 待验证假说

| 编号 | 可继续研究的主张 | 当前状态与优先验证 |
|---|---|---|
| HYP-01 | 可定义对某类跨系统比较有用的Ordo或统一指标 | 未确立；须说明编码、参照、组合与尺度变换，以及相对既有指标新增的预测能力；Q3 |
| HYP-02 | 一类相互维护机制能在不同领域支持可比的持续性结果 | 有模型线索，无跨领域普遍验证；先把一个具体系统的损失、补偿、外部依赖和速率对应到数据；Q2 |
| HYP-03 | 特定任务及环境变化使模块化更容易形成并降低全周期投入 | 形成与收益分别检验，不能从固定模块收益反推起源；记录接口更新、选择及替代架构；Q4 |
| HYP-04 | 某类知识共享和复用在现实中减少重复投入且维持质量 | 未完成系统实证；计入检索、验证、适配、更新和共同错误，比较相同任务质量；Q5 |
| HYP-05 | 特定偏好、规范、重复关系和治理改变公共投入及维护行为 | 模型可容纳，现实参数未定；测量真实外部选择、行动与履约，不先默认完全自利；Q6 |
| HYP-06 | 某种捐赠、承诺、服务和赞助组合改善持续维护与贡献者回报 | 待机制和经验比较；同质量期限下比较净额、续约、储备和实际任务，不合并不同赞助研究的指标；Q7 |
| HYP-07 | 开放接口及经营接入减少参与者协作负担，同时保持可验证交付 | 待检验技术、交易与治理三种边界的连接，不能只测API调用次数；Q4、Q8 |
| HYP-08 | AutoOS逐轮推广能改善有效发现、可信使用及长期满意 | 未试点；点赞与付费分开，保留样本、受众选择、误导及履约结果；Q8 |
| HYP-09 | AutoOS候选收费和公共回馈能够同时覆盖运营、维护及贡献支持 | 无实际预算验证；取得真实费用、成本、退款、贡献人数、付款时序与退出数据；Q8 |
| HYP-10 | 候选贡献认定方法能支持可靠贡献并限制错误分配 | 未确立；区分来源、权利、任务贡献、评分和分配目标，记录评审成本、复核及多身份风险；Q8 |

强普遍版本的增长、内部预测模型必然出现、单调记忆棘轮、最大熵产生和自组织临界性，按[旧命题处理表](../research/reviews/10-research-synthesis.md)分别处理；没有因列出这些研究方向就恢复其公设地位。

## 制度目标与评价选择

| 编号 | 目标或选择 | 地位 |
|---|---|---|
| NORM-01 | 支持知识访问复用、参与自主及明确的退出选择 | 项目制度目标，各开放维度与资源条件需分别说明；不是热力学开放的推论 |
| NORM-02 | 普通公共贡献拥有获得经济支持的通道 | 延续用户提出的方向；资格、足够程度及与其他目标的权衡未由物理或成本决定 |
| NORM-03 | 规则可核对，责任有人承担，利益冲突和争议可处理 | 治理目标，具体权限、隐私与透明范围需设计，不等于所有信息一律公开 |
| NORM-04 | 对总收益、分布、质量、风险及自主等结果赋权 | 必须显式选择；等权准线性总收益只是部分模型的比较基准，不宣称唯一公平标准 |

## 应用参数与候选设计

| 编号 | 参数或方案 | 当前状态 |
|---|---|---|
| PAR-01 | 技术费τ=5%，计费范围、含费或另加、每底层结算收一次 | 用户历史候选；范围尚有不同表述，主模型另加及较窄范围是比较场景，未定稿 |
| PAR-02 | 技术费回馈份额β=50% | 用户候选；基数、用途与管理费用扣法需确定，须与平台完整预算共检验 |
| PAR-03 | 首轮100人、扩散倍数、表现阈值 | 候选推广参数；授权预算、受众选择和真实性要求另列 |
| PAR-04 | 信息量与收藏数量的分配指标 | 直接乘积版本有PROP-19反例，不作为已可靠的默认计价；替代方式待比较 |
| PAR-05 | 实际维护成本、渠道费用、退款率、成交与续约、合格贡献人数 | 待采集、校准和注明期间，不用示例数字补成经营事实 |
| PAR-06 | 各轮模型中的r、p、g、δ、h、9.6预算及假设费用等 | 纯示例参数，与待测AutoOS参数分开；不是拟合值或推荐费率 |
| DES-01 | 资源本金、交易本金、公共回馈及平台运营用途分开，区分授权、收款、承诺、分配和到账 | Q8候选账务安排；不指定法定托管或支付服务，不代表已经实现 |
| DES-02 | 直接交易、事后贡献回馈及明确的维护委托分别安排 | Q8候选回报与责任设计；维护对象、期限、资金、验收及交接需落实 |
| DES-03 | 预算管理、贡献评审、付款与申诉职责明确，并保留规则版本和回避程序 | Q8研究建议；实际组织人选、权限与执行成本未确定 |

这些参数和设计是通用框架的应用输入，不是推导基础。Open Business 的有效性最终依赖 HYP-06至HYP-10 的检验及 NORM 项的公开论证。
