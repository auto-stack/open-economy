# 工作术语与跨层论证接口

日期：2026年11月12日。用途：落实[骨架复核](../research/reviews/32-framework-completeness-and-inference-audit.md)的第一项补充，供书稿和论文共用。正式编号仍以[79条总表](theory-register.md)为准；本页解释接口，未新增公设、正式命题或通用指标。

## 统一使用的口径

| 术语 | 本阶段怎样使用 | 不能由此直接认定 |
|---|---|---|
| 有组织性 | 在声明边界和研究性质下，关系与约束对结果有可辨认的作用（DEF-01、02） | 必有共同意志、净收益或道德价值 |
| Ordo／秩 | 保留通用组织理论的研究名称；讨论组织关系怎样支持能力与持续，并探索可比较的度量 | 已存在通用标量；热力学负熵、整齐、服从、财富或幸福就是它的数值 |
| 任务能力 | 给定任务、环境、行动、预算与期限下的成功率、质量、吞吐、恢复等表现（DEF-07） | 选定任务就是组织自身目标；单项表现代表所有能力 |
| 持续输入与吸收 | 分别记可用资源流、取得条件、吸收转换、损耗与维护；物理能流、工时、现金分别核算 | 资源越多生产力必越高；收入就是物理能量输入 |
| 生产力 | 在明确产出质量、投入和期间下的生产能力或效率；说明使用哪种劳动、总要素或任务口径 | 单纯扩大投入、提高收费或转移收入就是效率进步 |
| 杠杆 | 可实现、可重复使用或传承的工具、知识与组织安排，改变任务成本、可靠性或可行范围的机制候选 | 无成本固定倍增；每种技术都使整体改善；制度可只由物理规律解释 |
| 竞争 | 在人类互动中，参与者争取稀缺或不相容的机会、资源、收益或选择结果；注明竞争对象和规则 | 必然暴力、零和、有效或公平；生物选择等同有意争胜 |
| 合作 | 在本书人类共同任务中，以相互配合、互补投入或共同维护形成活动；分别识别共同意向、实际受益与自愿程度 | 所有人动机相同、受益相等或没有冲突；生物学合作判据可直接换成人类道德 |
| 影响力 | 在指定对象、目标、资源、渠道与时间下，调动他人改变行为的能力；另记文化体验形成的未来倾向 | 可动员就是因果贡献、正当权力或应得回报；存在固定财富换算率 |
| 财富 | 为人或群体提供用途与未来机会的资源、能力、资产及其组织条件；逐项声明物质存量、权利、知识、可用服务和估值口径 | 各类可直接相加；一方金融资产增加就是整体真实财富增加 |
| 货币与资金 | 货币的记账、支付及清偿安排分开研究；资金是某主体在某时点可支配的支付能力 | 货币必源于单一物物交换历史；有社会收益就有现金支持维护 |
| 贡献 | 对指定结果的作用；事实记录、反事实归因、合同承诺、价值评价与回报规则分别说明 | 工作量、影响力、价格或收入自动等于贡献；因果作用唯一决定应得 |
| 开放 | 分别说明访问复用、经营接入、规则透明、接口、治理及回报（DEF-18） | 开放一项就全部开放；公开记录等于共同决定或必有资金回流 |
| 演进 | 说明什么发生变化、怎样保留传递、何种差异被选择以及什么丢失；区分生命、学习、文化、技术与制度 | 存续者最有效或最正当；人类历史必朝同一目标前进 |

“共同能力”指特定关系支持的任务结果，不预设各成员单独完成不了，也不预设扣除所有成本后必有净增益。若声称协同增益，应给出可行的独立行动或其他组织方式作为对照。

## 每次跨层都增加什么

| 连接 | 必须新增的条件／证据 | 允许交付的结论 | 失败或停止外推的情形 |
|---|---|---|---|
| 物理实现→组织能力 | 状态、关系、机制、资源、任务及对照 | 这些安排在这些条件下支持某种表现 | 物理量相同而任务表现不同；指标随编码改变 |
| 维持→演进 | 变异、学习、保留、传递、采用与淘汰过程 | 能力怎样改变及保留下来 | 只有输入增加，没有创新或传承证据 |
| 人→共同活动 | 理解、动机、相互依赖、行动条件、身份及退出关系 | 可行性、参与、形成与维持各自的条件 | 总收益为正却无人能先投入，或关键参与者受损 |
| 竞争与合作→组织的秩 | 明确层级、关系改变、资源路径与任务结果；测量维护、纠错和适应 | 两类互动怎样形成、选择、维持或破坏关系 | 只见赢家收入、行动一致或内部凝聚，未见目标能力与外部结果 |
| 共同活动→经济 | 稀缺、用途、权利、需求、支付能力、交易与执行 | 生产、交易和回报能否连接 | 有用但无法收费；能收费却挤出更有用活动 |
| 知识复用→持续经营 | 上游权利、物理承载、服务工时、付款与维护合同 | 复制收益和维护资金分别成立的条件 | 使用增长但无人承担更新，或服务容量拥挤 |
| 技术潜能→制度选择 | 控制权、组织成本、收入风险、参与机会及可行替代制度 | 某条件下支持何种制度的比较判断 | 同一技术也支持集中控制；对照方案更可行 |
| 制度结果→值得支持 | 独立的价值目标、受影响者、权利底线与取舍理由 | 有条件的规范判断 | 效率提高却损害既定权利或将损失排给未计入者 |

这些是论证责任与识别条件，不是从物理学新推导出的普遍行为公设。个体可能追求自我维护、他人福祉、地位、探索或其他目标，不能预先用单一最大化假设解释全部人性。

## 竞争与合作怎样共同进入Ordo路线

研究的共同对象是**关系的形成、维持、选择与改变**。合作可以形成相互依赖和公共基础；竞争可以改变采用、资源和行动方向；两者也可能共同支持排他联盟、破坏公共基础或压制纠错。具体机制见[联合研究](../research/surveys/03-competition-cooperation-distribution/competition-cooperation-and-order.md)。

可以研究它们与组织的秩之间的直接机制联系；现阶段不采用“合作必增秩、竞争必减秩”或相反的统一符号定律。也不把“都影响组织结果”当作已经证明新Ordo指标有效。度量须相对现有网络、协调、可靠性及能力指标给出新增解释或预测（HYP-01）。

## 论文与书稿怎样分工

经济跨期接口已补[信用与再投入研究](../research/surveys/08-price-income-and-reinvestment/credit-investment-and-reinvestment.md)：真实资源、项目回款、可承诺外部支付、逐期现金与维护责任分别记录。相关模型和候选设计不新增普遍公设，也不把信用或融资金额定义为Ordo输入量。

本轮[形成与维护研究](../research/surveys/07-organization-formation/README.md)把参与、规则实施和维护支持分别处理，应用到[第四部分开篇](../book/part-04/01-formation-and-continuity.md)。这是机制框架与领域证据的补充，未将六项分析检查升级为普遍公设；原79条编号保持。

书稿用同一组问题贯穿各层；论文可以先限定对象，综述既有定义、机制与反例，再提出能够检验的局部连接。允许一篇论文只研究维护或协调，不承担证明全部经济理论的任务。后续若形成新定义、解析结果或实证发现，再连同条件审议是否进入正式总表。
