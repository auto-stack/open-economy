[Q3：熵、信息、复杂性与功能](research/reviews/04-measures-and-bridges.md)已完成本轮定向调研，明确物理与信息度量的条件性联系，并以[有限例子](research/reviews/04-measure-examples.md)核查不能直接等同的情形。建议暂保留 Ordo 为研究概念，统一标量尚未确立。

[Q4：模块、接口与层级](research/reviews/05-modules-interfaces-hierarchy.md)区分不同模块与边界，整理形成机制，并用[两个最小模型](research/reviews/05-modularity-models.md)比较返工节省、接口开销及局部与整体动态。结果支持有条件的模块收益，不支持模块越多越好。

[Q5：记忆、预测与复用](research/reviews/06-memory-prediction-reuse.md)区分保留记录、预测信息及行动收益，并通过[最小模型](research/reviews/06-memory-reuse-models.md)比较过时、策略失配、验证更新与共享错误。

[Q6：社会经济连接](research/reviews/07-economic-bridge.md)已完成本轮定向阅读与[模型核算](research/reviews/07-economic-bridge-models.md)，明确主体、偏好、信息、权利和执行机制是新增条件；技术可行、总收益、资金、参与及激励分别检验。

[Q7：开放成果的投入与回报](research/reviews/08-open-funding.md)已比较自愿贡献、条件筹资、成员服务和赞助，并核算[承诺、净额回流与多期预算](research/reviews/08-open-funding-models.md)。一期筹成、营业收入和期望收支均不能单独保证持续维护。

[Q8：AutoOS 开放商业](research/reviews/09-autoos-open-business.md)已结合用户历史方案，明确候选角色、资源与交易本金、公共回馈、维护报酬及责任交接，并完成[收费、退款与分配反例核算](research/reviews/09-autoos-models.md)。实际费率与运行效果仍待验证。
