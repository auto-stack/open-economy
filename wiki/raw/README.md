## 保存方式

- 原始 PDF 与 HTML 保留下载内容，不用研究摘要替代原文，也不覆盖原有版权与许可声明。
- 每项来源分配稳定编号，记录作者、题名、来源网址、获取时间、文件版本、下载状态与 SHA-256 校验值。
- `extracted.txt` 是从原文件生成的检索辅助文本。公式、表格和扫描页可能提取不完整，引用时回到原文核对。
- 检索返回结果单独保存为 JSON。检索命中不等于纳入阅读；仅在搜索结果中出现、未打开和使用的链接，不逐一下载全文。
- 获取失败保留尝试记录；只有已保存的原文才标记为下载完成。扫描件和网页提取的阅读方式在来源清单中说明。
- 分析、比较表和阶段判断保存于 `research`，与本目录的来源材料分开。未来按实际 AutoDown 导入规范转换，本轮先保留通用文件格式。
