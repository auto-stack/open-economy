# 三张真实论证卡的证据关联核查

2026年11月13日。回查三张已存在的论证卡、六项主张，结果是：**已有支持链总体可以追到原件或项目推导，但若干限制、更正与来源用途分散；维护频率假说的直接效果验证仍未提供。** 本轮未发现足以要求改写所选书稿科学结论的直接冲突，也未观察到上一轮人为错挂索引导致的误判。

采用目的性小样本，覆盖文献定理、经验结果、项目推论和待验证假说。没有随机抽样、独立盲评或真实使用者计时，不能估计全仓库错误率、完整率、关联记录的因果效果或节省时间。[核查协议](protocol.md)、[逐项记录](case-register.json)、[原件回查](reading-notes.md)和[核查前快照](../../../../../wiki/raw/round-49/before-state.json)保留。

其中四项适合细化行级定位或来源角色，一项保留直接效果证据缺口，一项原来已有足够明确的项目推导链。这个分类是对六个案例的说明，不是独立测量的缺陷率；“链接较深”不能直接算作“来源不存在”。

## 反向材料并非同一种东西

R01是真正修正原假设范围的作者更正；R02是定理适用条件；R05是研究内的年龄组对照及注意、互惠等替代解释。R03与R06的条件外解析情况，只说明不能越界复用，不推翻条件内的式子。R04目前缺少直接效果验证，不是已经找到了否定该假说的实验。

把这几类都塞进一个“反证”字段，会制造新的误读。逐项记录因此写明材料作用：支持、缩小原假设、限制推广、提示替代解释、项目推导或尚无直接效果资料。每项还注明本轮未穷尽相反文献，不能把缺失项自动解读为“没有反证”。

## 与合成对照怎样连接

上一轮固定规则和明确归属字段，在生成时就知道哪些材料属于哪个主张。真实记录需要先判断来源到底支持哪一层意思。例如，生理学综述的间歇节能提案不能标成组织维护干预的效果验证；儿童共同任务结果也不能标成成人通知和交接机制的验证。

本轮能确认这种语义审查工作确实存在，不能把它的成本压缩成扫描若干记录或建索引。没有测量实际耗时，也没有对照同一读者在三种保存方式下的表现。因此，本轮为前一轮补上了真实来源用途的案例，没有验证它在现实中的节时幅度，更没有复现其人为错关联的失败频率。

## 已修复与未解决

三张卡均保留原主张和论证地位，补就近的原件位置、变量定义、来源用途及核查入口；章稿正文未改。更正、结果与替代解释可以更直接追查，仍不等于未知的反面材料已经被覆盖。

没有完成的工作包括：维护干预的直接效果资料、现实成本与行为参数、其他情境推广、模型失配和动态恢复，以及完整相反文献检索。下一步适合将“来源作用、反向材料类型、实际覆盖与未知项”整理成轻量核查格式，再选少量来源异议较大的案例核验，而不是一次性铺满全仓库。

本轮资料见[第49批归档](../../../../../wiki/raw/round-49/README.md)，原件按旧路径和版本复用，没有新增检索、下载、来源编号或外部实读范围。[综述0.3](../review-2026.md)承接结果；本轮没有新增完整书章，仍13章讨论稿。旧审计回执按各自修订保留，不能用旧卡片校验值代表修订后状态。
