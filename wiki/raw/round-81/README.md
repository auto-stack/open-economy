今后若终端客户续约改善、机房建设放慢而外行业信用平稳，投资重估的解释更强。若抵押融资与短债续借同时吃紧、银行对无关行业限贷，并有跨境美元融资、就业和实际支出的广泛恶化，应上调系统性风险判断。这里列出的是复核条件，未估计危机概率。
