# 内部研究资料目录

Git版本只携带书目、读取范围和经检查的描述记录；原文、整页OCR和检查图通过可选[独立来源包](../archive/README.md)保留。没有安装原件时，本地扫描链接属于可选资料缺省，不代表哈希损坏或已完成原文核验。

日期：2026年11月12日。基础目录由当时36批raw元数据和项目文档派生，供写作查阅与未来知识库整理使用；该轮没有新增网络资料。后续新增的[第37批融资复核材料](../raw/round-37/README.md)与扩读以单独记录连接，不覆盖36批的冻结基线。

先看[可读来源目录](SOURCES.md)，按编号、题名、版本和元数据所记读页查找。结构化数据见[source-catalog.jsonl](source-catalog.jsonl)、[CSV](source-catalog.csv)和[编号／版本组](work-groups.json)；[派生注释](source-annotations.json)记录本轮额外观察，不覆盖原元数据。

后续已完成[三份关键扫描的13页文字补充](../derived/cited-page-text-2026-11-12/README.md)，含逐页图像、原始OCR、校订文字与公式校核。[派生文本目录](derived-text-catalog.jsonl)单独记录新状态，以原件路径和SHA256关联来源；原始文字层限制及v0.2冻结目录／检索结果保留。不是整篇OCR或AutoDown已导入，L189一处原文编号疑点另列。

v0.2基础目录的193条档案记录对应192个编号槽位，包含失败及候选；不等于192篇采用或通读论文。记录状态为126条PDF容器、29条HTML／目录容器、24条部分／转录材料、1条其他载荷和13条获取失败／未取得线索。容器存在不证明整个作品已经归档、读完或经过独立验证。

上述统计是v0.2冻结目录口径。第37批未增加文献编号，新增L189、L190对照副本、L190669–674页扩读及作者书目核对；参见[后续读页与版本记录](source-followups.jsonl)。L190扩读仅公式和关键段落经图像复核，原始正文OCR不是逐字校订全文。

关键用法：先核对实际版本，再看读页与限制，最后打开相应原件或部分材料。对于扫描、出版预览、书介和工具文字，按本条范围使用；不要把它们自动标为全文。许可文字保留，实际公开再分发范围本轮未评估。

执行过程见[内部基线报告](../../research/reviews/37-internal-knowledge-service-baseline.md)、[八项证据回答](../../research/baselines/internal-knowledge-2026-11-12/answers-and-evidence.md)及[维护队列](../../research/baselines/internal-knowledge-2026-11-12/maintenance-and-observation.md)。检索使用助手预先指定词项，当前没有上线AutoOS／AutoDown问答接口，也未完成AutoDown格式转换或导入。

原件、历史对话、获取失败日志和运行缓存的用途不同。目录不把历史AI讨论或出版物中的指令当用户要求，也不把运行缓存当研究来源。重跑盘点会更新派生输出；输入有变化时应另存协议、快照和回执，避免混合两次结果。
