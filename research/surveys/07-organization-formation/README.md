# 从共同收益到持续组织：竞争、合作与维护的定向survey

日期：2026年11月12日。性质：问题导向的定向综述与机制比较，非系统检索穷尽或已建成的通用组织定理。本轮新增L182–L184，沿用Coase、Hart–Moore、合作演化和既有维护研究；原件见[第34批](../../../wiki/raw/round-34/README.md)，版本与实际读页见[阅读记录](reading-notes.md)。

后续框架收束形成[四种人群组织的共同机制与边界](organization-comparison-and-boundaries.md)，将照护依赖、企业合约、开放共同体与公共授权分别处理；属于分析类型对照，没有新增案例调查或原文扩读。

## 核心问题

第 71 轮追踪[共同活动中的意义、受益与贡献认定](meaning-and-participation-over-time-2026.md)。同人跨期访谈检验参加理由是否变化，结案记录和候补对照分别观察组织认定与服务对象结果。民权项目申请者的长期追访补入跨角色参与。[第 66 批原件与读页](../../../wiki/raw/round-66/README.md)

第70轮追踪[履约争议、决定权与复核之后的合作](disputed-performance-and-review-2026.md)。风机基础失效后双方先安排修复，三级法院再解释责任。淘宝投票与社群申诉实验可检验谁看得到异议、谁决定、谁执行；编辑者与家庭随访则把观察延伸到原共同体参与和原双方联系。[第65批原件](../../../wiki/raw/round-65/README.md)

第69轮补入[共同承诺的形成与修订](reliance-and-revision-2026.md)。专用投资实验能将同一局中买方的先期支出、卖方的外部机会和双方重谈相连；预约与跨班交接记录则分别核查，变更后释放的时段是否用上，转交的任务是否有人接、有人报完。形成组织所需的一种能力由此可以具体比较：成员改变原计划时，依赖原安排的人还能继续做什么。[第64批原件](../../../wiki/raw/round-64/README.md)

为什么一项共同活动能够带来收益，却不一定形成持续组织？竞争和合作怎样共同影响关系的形成、采用、维持与改变？本轮聚焦人类组织的自愿参与和规则采用，强制、依赖照护与历史继承作为外推边界；不将这一套直接当作生命或所有物理组织的起源理论。

组织的形成不要求新登记法人、所有目标一致或完全自足。本书按既有定义识别相对持续、对声明任务具有作用的关系安排；是否产生净增益、是否形成新的生物个体以及是否值得支持分别判断。

## 1. 用六项检查代替“有收益就会组织起来”

| 检查 | 要解释什么 | 可能断在哪里 |
|---|---|---|
| 任务可行 | 投入与关系能否产生所需结果，质量与资源是否相容 | 技术想象成立，但关键能力、时间或资源不可得 |
| 参与和承担 | 谁愿意参加，承担什么成本，实际外部选择是什么 | 总收益为正，部分人承担损失，或有利却无力先投入 |
| 启动与协调 | 谁先投入、如何识别伙伴、怎样选方案和设规则 | 都等待别人先做；方案和分担无法达成可执行安排 |
| 规则的接受与执行 | 谁受约束、谁判断、怎样核验、怎样纠错 | 文本存在却无人执行；约束不对称使参与者拒绝 |
| 维护组织条件 | 谁维护工具、资料、权限、资金和接替能力 | 当期产出成功，支持下一期活动的机制耗损 |
| 改变与外部结果 | 怎样修订、迁移、分拆或终止，谁承担外部代价 | 内部凝聚或胜出，却牺牲长期能力或外部群体 |

这些是分析检查，不是六个已经证明适用于所有组织的独立必要充分条件。规则可来自协商、习惯、委托或已有公共制度；不能预设所有组织先经历平等成人的一致同意。

## 2. 本轮材料怎样检验这条解释

**制度形成不等于公共成果生产。** Kosfeld、Okada与Riedl的模型让参与者先选择参与，再决定实施，最后投入公共品。形成规则本身有成本，非成员不受制裁；实验中一些提高成员物质所得的子群体安排仍被拒绝。它支持把参与、实施与受益分开，不能唯一判定所有拒绝都是公平动机。模型预置可执行制裁，并未解决怎样建立可靠执行者。[L182](https://doi.org/10.1257/aer.99.4.1335)

**竞争与合作可以通过制度选择连接。** Lo Iacono等的多实验室重复研究让参与者在有、无同伴奖惩的环境之间逐轮选择；七个实验室中五个满足全部预注册重复标准，其余结果较弱但仍偏向奖惩环境。这里观察到的是特定制度选择和公共品合作，不能外推为惩罚、市场竞争或自由退出在任何环境都有效。[L183](https://doi.org/10.1093/pnasnexus/pgad091)

**维护规则仍需要投入。** Rustagi、Engel与Kosfeld将埃塞俄比亚49个森林使用群体的行为测量、巡护调查与森林结果相联系。条件合作倾向与结果存在相关联系，巡护也占用工时；但这不是随机建立组织或分配巡护制度的试验，不能用相关性断言其唯一因果机制。该案例涉及会减损的森林资源，不能直接套用到可复制知识。[L184](https://doi.org/10.1126/science.1193649)

已有Coase的企业协调成本和Hart–Moore的专用投资研究，还提供两项竞争解释：有些关系因市场缔约／协调代价而被组织起来；有些投资因事后分配和可验证性问题不足。这些机制可以共存，不能只用公平、奖惩或共同目标解释全部组织。沿用[Coase既有读页](../../reviews/01-reading-notes.md)和[Hart–Moore既有读页](../../reviews/16-reading-notes.md)，本轮未新增通读。

## 3. 竞争与合作怎样进入Ordo机制

第一条是**共同基础与实现差异**：相互配合形成知识、接口和维护安排，不同方案通过比较、选择和采用改变关系。共享不必消除竞争，竞争也不自动支持共享基础。

第二条是**内部与外部的连接**：组内共同投入，可能影响组间选择；组间竞争又改变组内分工和回报。但是选择可能奖励收费、排他或操纵能力，而非声明任务的质量。没有独立结果指标，不能由赢家倒推“更有秩”。

第三条是**生产与治理的相互依赖**：持续活动需要有人核验、修订和接替，治理本身消耗资源。过去贡献奖励、当前履约报酬和未来维护承诺必须分开。谁负担规则维护，会反馈到下一轮参与与竞争。

这三条是组织关系改变的机制候选，不是Ordo数量定律。任务能力、持续性、适应、行动一致和规范评价分别观察；本轮没有新增通用标量、公设或正式总表编号。

## 4. 反例、竞争解释与可否证假说

| 候选解释 | 需要观察 | 会削弱解释的结果 |
|---|---|---|
| 只因共同收益不足而未组织起来 | 总收益、启动支付、分担、规则接受分别测量 | 技术与支付有余仍因约束不对称或程序失败而拒绝 |
| 明确维护责任改善持续性 | 已履约维护、缺陷、交接、资源成本及参与 | 责任明确但能力／预算缺失，或手续成本抵消效果 |
| 共享基础＋方案竞争改善能力 | 基础维护、采用质量、重复投入、迁移与长期风险 | 只出现评分竞争、耗尽上游或形成新的接口垄断 |
| 退出选择促使规则改善 | 实际可迁移能力、退出后的资源与权利、制度修改 | 弱势者无法迁移，或竞争吸走维护资源而无替代 |

形成也可能来自资源集中、法律指定、继承或强制；退出少未必代表高度认可。即使某个群体内净收益提高，也需另查基本权利、外部损失与机会分布。家庭照护、学校、公共服务不能只按本轮自愿公共品实验解释。
