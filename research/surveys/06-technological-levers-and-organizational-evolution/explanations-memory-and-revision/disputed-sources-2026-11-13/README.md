# 轻量来源核查格式与两个争议案例

2026年11月13日。已将上一轮字段压缩为[六项核查格式](../../../../../shared/source-check-format.md)，并用两组已有实质争议试填：

- [跨文化博弈的偏好、信念与理性](case-01-preferences-and-beliefs.md)：目标文章、Binmore评论和作者答复同在一份校样，需区分说话者和理论对象。
- [足球、认同与冲突](case-02-football-and-conflict.md)：原文、更正、复核和答复针对不同结果和识别问题，需分别保留当前用法。

试用后保留的最小结构是：主张与地位、来源及作用、反向材料、适用边界、已查与未知、当前用法与复核。复杂争议在来源栏另列说话者、版本、对象和读段；普通主张不必照抄争议案例的长度。不批量给全部卡片新增空表，也不设置来源数量或完整性评分。

两个案例使格式暴露四个具体问题：同一文件不等于同一立场；针对某种解释的质疑不等于推翻一般理论；一篇论文的不同结果不能一起判定；官方网页也可能同时呈现原摘要和更正入口。反向材料与回应都要写明针对对象，不能靠引用数量或最后出现的文件决定胜负。

本轮补读足球争议中样本及识别相关指定段，未重跑数据或核完全部往返，故仍保留未裁决部分。格式能够表达这些缺口，不等于已经解决缺口，亦没有真实用户效率、维护成本或全仓库质量改善的效果估计。

方法见[试用协议](protocol.md)，版本与读段见[逐项关系](cases.json)及[第50批归档](../../../../../wiki/raw/round-50/README.md)。原始论文继续复用旧路径，新增出版网页与失败响应单列。下一步可把六项格式用于少量真正进入下一份章稿的主张，观察维护负担，再决定是否调整，不先扩大为全仓库工程。
