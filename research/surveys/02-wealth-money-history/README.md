## 一、研究必须分开的三种历史

第二轮之后现已补充[中国纸币与雅典银币深化](china-athens-deepening.md)，以宋代编纂文本、元代接受稿、钱币发掘报告、验币铭文及公共收支记载核对机制；据此形成[叙述顺序比较](narrative-options.md)。下文继续保留首版范围，后续补强及实际读页另记，不将新取得文本反填为先前已读。

1. **经济活动的历史**：人们何时、怎样获得食物、工具、储备与生产能力，怎样协作、交换、征收和分配。需要遗址、物件、账簿、法律、契约等证据，不能仅凭后人的理论倒推。
2. **概念和学说的历史**：Aristotle、Smith、Marx或Menger怎样解释财富和货币。作品是其思想的第一手材料，其中关于上古社会的叙述仍须另查史料。
3. **特定制度的形成与变化**：某种钱币、纸币、存款或支付网络，在什么地方、对哪些人有效，凭什么被接受和维持。一个制度晚期的运行方式，不能自动成为所有货币最初起源的解释。

本轮思想史材料比较充分，实际形成史只取得若干入口。不能把下列作者年代排成全人类实际经历的阶段，也不能把民族志中的当代社区当作史前社会的活化石。

## 二、工作区分：暂不选定财富的唯一终极定义

| 对象 | 本轮识别方式 | 容易混淆的对象 |
|---|---|---|
| 物质与生活条件 | 食物、住房、工具、可使用的自然条件等；另查数量、质量、可达性和维护 | 不等于其市场售价；天然存在也不等于人人可得 |
| 生产与协作能力 | 技能、知识、设施和可持续履约的协作关系；必须指定任务及维持条件 | 不把组织规模、信息量或所有复杂结构都算成财富 |
| 所有权与索取权 | 谁可使用、排他、转让或主张某项给付，谁承担义务 | 一项权利的私人价格上涨，不必然增加社会可用成果 |
| 货币计价的资产与净财富 | 既定制度、价格、时点及核算边界下的资产和负债 | 资产总额、净额、收入和实物产出不互换 |
| 福祉与实际机会 | 人怎样生活、能做什么、受到哪些损害；评价标准需说明 | 支付能力不是人的尊严、意义或全部福祉的尺度 |

这是一组分析用的区分，不是将五项简单相加的新财富公式。财富史也必须研究自然条件、攫取、破坏和不平等：某主体积累财富，可能来自创造、重分配、占有或重新估值，各自需要辨别。

## 三、财富来源的思想史：相邻问题，不能合并成同一种价值论

| 材料与历史位置 | 本轮读到的核心解释 | 带给我们的研究问题 | 不能据此断言 |
|---|---|---|---|
| Aristotle，《政治学》第一卷VIII–X；古代文本，Jowett英译，L85 | 家庭生活所需的财物与无限求财有别；同一物品有使用与交换的用途；钱币不等同生活供给 | 财富与生活目的、物的用途、积累边界怎样关联？ | 其自然秩序、反取息及等级观不作为本书规范；其货币叙述不等于已核实的起源史 |
| Cantillon，1755年首次出版；本轮用Higgs译本1959重印的电子版，L97 | 土地提供财富的材料，劳动赋予形式；财富联系生活所需、便利与享受 | 自然禀赋和人的加工怎样共同形成可用成果？ | 不将所有财富还原为劳动；也不把18世纪土地经济的表达直接当作当代完整生产函数 |
| Smith，1776年首次出版；Gutenberg后世文本，L83复用 | 第一卷把劳动生产力、分工、交换和市场范围联系起来；并讨论货币对交换的帮助 | 协作与专业化为何可能提高供给？运输、需求和交换机会怎样限制它们？ | 不把全部合作归结为交易；不把交易倾向是人类独有的说法当作现代实证；其生产性劳动分类也需另行检验 |
| Marx，《资本论》第一卷第一章，1867年首次出版；MIT节录PDF，L86 | 区分使用价值、价值及其社会形式；物质财富涉及自然材料与劳动，价值分析又有不同抽象条件 | 生活有用性、劳动过程、社会关系和货币表现怎样区分？ | 不把“物质财富”和Marx特定的“价值”概念等同；未复核整部资本与剩余价值理论 |
| Jevons，1871年首次出版；1888年第三版电子本，L87 | 效用联系主体的需要与供给状况；交换比率和交换带来的总收益不是同一问题 | 同一物品为何对不同的人有不同用途？为什么双方可能同时获益？ | 不以主观效用替代生产、权利或权力的研究；不默认效用可在人际间直接相加 |
| Romer，1990年模型，L84复用 | 非竞争性的设计与知识可重复使用，但研发、技能和具体生产仍需投入；可排他性影响收益与激励 | 知识复用怎样改变生产与投入回收？ | 不把模型当成史前起源证据；不推出免费执行、没有维护成本或开放制度必然最优 |

**第一轮判断**：这些材料分别解释供给、用途、生产力、社会形式、评价及知识积累。它们让“财富怎样涌现”成为一组可以分别研究的问题，还没有共同证明财富是某一个物理量。把它们全部写成“熵秩提高，所以财富增加”，会跳过最需要证明的关系。

## 四、货币形成：先辨认功能，再比较形成路径

本轮暂以计价单位、交换媒介、支付与债务清偿手段、跨期持有等功能为观察入口，另外记录发行者、适用人群、可转移性、赎回条件及执行规则。它们可以由同一载体承担，也可能分布在不同载体或制度中。

三个辨认门槛：有记录不等于有货币；有债务不等于债权能广泛转让；有某种贵重物品不等于它在相关群体中承担货币功能。货币化也不是只能增加、不能收缩的单向过程。

| 解释路线与材料 | 解释的机制 | 本轮证据性质与约束 |
|---|---|---|
| 商品交换与可售性：Smith第一卷IV、Menger 1892，L83/L88 | 直接交换存在匹配障碍；更容易再交换的商品可能被接受作中介，接受习惯进一步扩展 | 是重要的形成机制。Menger同时承认国家规范铸币的作用；本轮未取得能够证明各地都依此顺序起源的史料 |
| 商品价值的货币形式：Marx第一章“货币形式”，L86 | 特定商品通过社会习惯占据一般等价物位置 | 属于其商品关系理论中的形式分析；不是本轮已逐地验证的考古编年 |
| 信用与清偿：Innes 1913，L89 | 一次交付可换取债权；债权被接受、转移或抵销，使交换不必每次以另一实物同时完成 | 原文提供与商品中介不同的解释；其中关于全历史和全社会的强断言尚未独立核实。也不能把任何私人欠条都叫货币 |
| 法律与支付制度：Knapp德文1905、英译1924，L90 | 从支付手段及其法律承认理解货币，材料本身不足以解释全部货币现象 | 只读英译开头两页的部分工具文本；不冒充全书阅读，不据此论证所有货币都由征税创造 |
| 记账与符号系统：Schmandt-Besserat作者研究网页，L93 | 对物资、交付和义务的计数记录，与城市及管理活动相连；作者提出代币到文字的解释 | 属于考古研究者的综合解释，非本轮独立重建的遗址数据；不能从计数代币直接跳到流通货币或“所有货币先有国家债务” |
| 物物交换与货币的共存及逆转：Humphrey 1985，L91 | 在特定贫困、自治、信任和贸易条件下，直接交换或延迟交换可以在已知货币的地区扩展 | 有1979–80年尼泊尔—西藏边境Lhomi民族志与比较讨论；限定了单向阶段论，不证明史前从未有过物物交换 |
| 现代银行货币：英格兰银行2014说明，L94 | 银行贷款可同时形成贷款和存款；该创造受风险、盈利、监管、持有人行为和政策等约束 | 是特定现代制度的官方解释，原PDF本地未取得，只归档选段工具文本；不是货币最早起源的历史证明，也不是无成本创造真实资源 |

这些机制并不总是互斥：商业交付、信用、金属、政府认可、税收义务与清算网络，可以在某一历史过程中彼此结合。我们需要研究谁接受谁的承诺、怎样兑现和转移、为何维持或失效，而不是提前宣布只有一种机制有资格叫起源。

## 五、逐项检验用户提出的交易、合作与竞争关系

| 用户提出的关系 | 第一轮处理 | 需要补充的条件或证据 |
|---|---|---|
| 交易是合作的一种形式 | **保留为有解释力的工作框架**：双方通过相互配合实现各自无法以同样方式单独获得的结果，不要求出于善意 | 明确交易是商品买卖、延迟给付还是一切权利转移；广义合作不应偷换成道德上的善或必然公平 |
| 交易双方是合作关系 | **在交易实现和共同可得收益层面成立的条件性解释**；同一次交易也可能存在价格谈判、违约和信息冲突 | 自愿、知情、外部选项、履约和风险要具体说明；被迫出售、欺诈、第三方受损不能用双方签字排除 |
| 同类供货方或同类买方竞争 | **可替代机会重叠时的机制命题**；替代性、订单或资源约束决定竞争程度 | 同侧主体也可能联合采购、共同研发或共享物流；这些是分析例子，不是本轮新取得的历史案例 |
| 货币首先基于交易 | **拆开研究，暂不当成普遍历史定律**：交换可产生货币需求与接受机制；历史上的计价、支付和债务安排须分别考察 | 若交易仅指现货自愿买卖，现有材料不能支持其为所有货币的唯一前提；若包括税赋、赔偿和债务安排，就需承认其关系性质不同，不能靠扩大词义证明 |

### 一个分析例子：共同获益与分配冲突可以同时存在

假设一单位物品，买方以某共同货币尺度表示的最高支付意愿为v，卖方交付的机会成本为c，成交价为p。这是刻画已有货币制度下的交易关系，不用它推导货币起源。假设双方知情、自愿且履约，没有额外交易成本、风险或第三方影响；这里只比较两人的货币等价收益，不把它解释为人际可加的全部福利。

- 买方增益为v−p，卖方增益为p−c。
- 当v>c且c<p<v时，两人都比不交易获益；两项增益之和为v−c。
- 在c、v固定的这个例子中，提高p将部分收益移向卖方，不增加这项总和。双方在达成交易上有共同利益，在选择p上有利益差异。

这是定义与假设下的核算，不是对现实交易普遍互利、公平或增加社会净财富的证明。现实还要研究外部选项怎样形成，权利为何归某人，损害由谁承担，支付和信用制度怎样改变可行的生产与交易。

因此，我们可以把合作与竞争当作**指定任务、资源、关系和层次下的作用方式**。交易不必因为有竞争就失去合作性质；也不能因为具有合作成分，就忽略剥削、强制或损害。这一处理可以接回共同承诺和多种组织的研究，但不自动成为新公设。

这里的合作指相互配合实现结果；它还需要与生物学特定模型中按成本与他者收益定义的合作、互利，以及博弈论的合作博弈分别映射。不能仅因词语相同，就宣称上述交易核算已经继承了某个合作演化模型的全部结果。照护、共同生产和共享知识也可能具有合作性质，不必全部化约为买卖。

## 六、这一轮能够支持什么，暂时不能支持什么

| 地位 | 本轮结果 |
|---|---|
| 文献中确有的区分与机制 | 用途与钱财、物质财富与特定价值概念、生产力与交换机会、信用清偿与现货中介、法律承认与载体材料，分别有明确原文入口 |
| 有限经验支持 | Lhomi案例说明货币化与物物交换不是必然单向替代；特定银行制度可通过贷款形成存款。二者适用对象完全不同 |
| 条件推论 | 在上述交易假设下，互利区间可以存在，合作实现与分配冲突可并存；价格转移不等于额外生产 |
| 候选研究假说 | 更可靠、可转移和可清偿的承诺，可能扩大跨时空协作；节省的协调成本能否超过治理、执行及风险成本，需要案例和比较模型 |
| 仍需独立论证的价值主张 | 财富应服务何种生活、合理分配、最低保障、开放程度与参与权，不能由成交或组织存续直接决定 |
| 尚未成立的结论 | 财富等于低熵或通用Ordo；全人类先以物易物后有钱再有信用；所有货币都只能由国家产生；凡交易皆公平；Open Business是唯一必要制度 |

**暂定研究判断**：交易作为合作，适合继续发展为经济连接的一个重要机制；财富与货币则需要分别追踪生产、评价、权利、记账、支付和清偿，再研究它们的反馈。目前材料不足以将其中任一路线固定为全书的唯一发生顺序。

## 七、第二轮应怎样补，何时再决定书中的论证

优先补一张“历史事件—原始记录—解释竞争”矩阵，至少包括：古代近东账簿与支付；一种古代铸币制度；中国纸币的私人与官方演变；欧洲银行、存款与清算。每例都记录计价单位、载体、发行/记账者、接受范围、兑换/清偿、强制义务、失效条件及证据年代，不只摘取支持某学派的句子。

财富侧还缺：重商主义与重农学派原典、创新与资本形成理论、土地和公共资源的占有史、家庭与照护劳动、跨地区贸易及征服、现代资产核算与分配，以及生态约束。货币侧还缺非洲、美洲、伊斯兰世界、跨境支付和殖民货币经验。Grierson只作未读线索，不把社会赔偿起源说当成本轮证据。

选取两个有对比性的案例完成证据补强后，再提出第五部分的章节候选及明确取舍：哪些概念先讲，哪些机制能推导，哪些只能叙述历史，哪些制度选择仍需比较。AI与机器人如何改变生产和收益权，需要建立在这些区分之上；本轮尚未据此扩写或定调经济正文。
