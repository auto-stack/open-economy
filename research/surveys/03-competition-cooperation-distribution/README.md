## 对用户主张的逐项定位

下表是本轮临时论证账，不增加正式79条总表编号。“有机制支持”表示在明确条件下能发生，不表示已测得全国、全行业的普遍程度。

| 研究主张 | 本轮判断 | 还需要什么 |
|---|---|---|
| 市场竞争激烈仍可能不公平 | 有机制支持；竞争结构与程序公平分别描述 | 明确公平标准，比较具体行业与受影响者 |
| 利用暴力、注意力局限与信息差，可以获得非生产性优势 | 有条件支持；三类可作分析入口，但重叠且不穷尽 | 区分未经授权的占取、欺骗、专业知识和合法执行 |
| 不公平手段更容易获利 | 条件命题；取决于额外收益、识别、追责及未来损失；不保证长期超额利润 | 成本、收益、发现率、补偿和声誉的真实数据 |
| 劣者能够排挤优者 | 逆向选择等模型支持特定路径；不要求每次都有故意欺诈 | 质量可识别性、买方支付意愿、优质供给退出及替代解释 |
| 丛林式竞争必然导致财富集中和垄断 | 过强；可能存在攫取与权力反馈，也有规模、网络和先发等其他路径 | 将私人积累、市场份额、进入障碍与社会损害分别识别 |
| 缺少监管是重要原因 | 治理功能有条件必要；国家监管、行业认证、平台规则和社区自治须比较 | 有效性、成本、俘获、执行权与申诉；不能只数规则多少 |
| 炒作加欺骗最终就是庞氏骗局 | 需改写；庞氏的关键是以新投资者资金支付旧投资者 | 分别追踪信念、交易、资产、现金流与欺骗行为 |
| 经济学避谈这些问题与合作 | 作为学科整体判断不成立；本轮原始文献已构成反例 | 若指教材或公共叙事低估，需要另做内容及教学史调查 |
| 开放共享具有重要经济价值 | 机制与估算支持其重要性；免费使用不等于零成本或零价值 | 维护投入、回流、受益范围与可替代方案的长期证据 |
| AI、机器人、元宇宙使合作主导市场必然取代旧市场 | 待验证的趋势假说；技术也能强化瓶颈控制 | 任务与行业、开放维度、时间范围、集中度、迁移能力及反例；本轮未完成机器人或元宇宙专题 |
| 分配是合作效果最重要的因素 | 分配是关键条件之一；普遍首要性尚未建立 | 与任务依赖、能力、信任、协调和维护的相对影响比较 |
| 按贡献分配优于现有安排 | 值得研究的规范提案及机制假说；尚无统一指标或已验证优越性 | 贡献对象、反事实、共同作用、保障、激励、抗操纵和争议处理 |

## 对全书论证的影响

建议在“人性与规范”到“交易与财富”之间，明确增加**规则如何影响合作与竞争的方向**这一连接。认知局限既是普遍的人的条件，也可能被制度保护或被有意利用；不把受害归咎于个人“不够聪明”。稀缺资源、退出依赖、法律权利和组织权力同样重要，不能都还原为心理弱点。

合作和竞争不是相互排斥的时代标签。同一行业可以在基础设施上合作、在服务上竞争；一个内部合作良好的联盟也可能对外排他。书中需同时说明关系、层级、活动和外部影响。

由此可以提出更强的应用问题：**当公共知识与自动化能力被多人共同使用时，怎样让可验证的增益、必要维护和合理回报相联系，并限制攫取、锁定与规则俘获？** 这能为Open Business提出设计要求；尚不能证明AutoOS的某一具体实现具有唯一必要性。

本轮只更新研究入口和优先任务，六部分工作框架、纲领0.3、79条正式总表及八章既有正文保持其原有地位。后续候选章节与论证顺序见第二专题末节，不急于写正文。
