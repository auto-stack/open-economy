# 竞争、合作与组织的秩：联合研究补充

日期：2026年11月12日。性质：对既有专题的机制整合与定向补读，不是完成新的系统综述。回应用户提出的“竞争和合作应该一起讨论，且都和秩有直接关系”。共同口径见[术语接口](../../../shared/concept-interfaces.md)，书稿修订见[第三部分第1章](../../../book/part-03/01-cooperation-and-common-capabilities.md)。

## 1. 把关系作为分析单位

不要先把个人、公司或整个时代归为“竞争型”或“合作型”。先写清：谁与谁，在什么任务上，围绕什么资源或结果，按照什么规则，在多长期间内发生什么关系。同一对行动者可共同生产、就剩余讨价还价，并竞争下次经营机会。

| 要区分的层面 | 合作与竞争怎样并存 | 必须再问 |
|---|---|---|
| 目标与利益 | 完成项目是共同利益，份额与主导权仍有分歧 | 可行总收益怎样到达承担投入者？ |
| 行动与方法 | 共建接口和知识，竞争实现方式或服务质量 | 是否能迁移，是否阻断他人使用共同成果？ |
| 组织层级 | 组内协作可以与组间竞争同时存在 | 组内收益是否依赖对组外转嫁损失？ |
| 时间 | 当前竞赛选方案，随后共同维护；也可能竞赛耗尽后续维护资源 | 形成、采用、运行与更新期的结果是否不同？ |
| 规则 | 共同遵守的规则可以容纳竞争；参与者也可能联合操纵规则 | 谁定规则、能否申诉、谁承担执行成本？ |

人的意向性合作与演化生物学合作分别使用本领域判据；选择过程不要求个体有竞争意图，观察到一起行动也不足以识别自愿、善意或共同理解。延续L51、L56、L57的范围，见[既有合作研究](../../reviews/12-cooperation-evolution.md)。

## 2. 与秩的关系应落实为四条机制

**形成与维持。** 相互配合可以建立分工、接口、信任和共同基础；利益冲突又可能使承诺和维护落空。是否形成新的组织层级，仍需解释冲突控制和持续依赖，不能只看一次互利。

**探索与选择。** 不同主体保留多种方案，经比较、模仿、采购或退出改变资源流向，可能改进任务能力。竞争也可能只选择擅长收费、操纵评价或控制入口的方案。选择标准、知识传播、损失承担和替代可能性决定方向，而不只是“竞争强度”。探索与利用的不同任务见[一致性与适应](../05-firm-authority-and-democracy/coherence-and-adaptation.md)。

**约束与纠错。** 共同规则、可核验承诺、问责和迁移接口，可能把争胜限制在可接受方法内；联盟也可能把规则变成进入障碍。竞争的存在不能代替执行，规则的存在也不能证明公平，见[不公平竞争](unfair-competition.md)。

**尺度与外部结果。** 一个联盟内部更一致、更富有，可以与其他人的能力、公共知识或长期环境受损并存。内部关系的有组织性、指定任务的能力、整体净结果和伦理评价要分别报告。

因此，竞争与合作都参与组织关系的形成和演进，均可与Ordo研究建立机制联系；目前没有采用二者到通用Ordo标量的换算式。不是只要资源重新集中、行为更加一致，就能判断整体“增秩”。

## 3. 本轮新增的有限经验锚点

L181 Bornstein、Gneezy与Nagel（2002）研究最低努力协调博弈，所读首轮设计让两个七人组比较组内最低选择，并设置无组间竞争的对照。在该实验范围内，竞争处理的平均选择高于对照。这给出“组间竞争与组内协调能够同时研究”的具体依据，不证明竞争总提高社会福利、组织稳定或通用Ordo。[原论文](https://doi.org/10.1016/S0899-8256(02)00012-X)；[本地25页原件](../../../wiki/raw/round-33/L181-bornstein-gneezy-nagel-2002/original.pdf)。

实际选读PDF／印刷页1–7，含首轮设计与部分结果，视觉核查第4页。没有逐页审阅8–25页；摘要提及的后续奖金处理不作为本轮独立核查结果，也不复算显著性或声称完成可重复性验证。完整版本、范围及检索排除项见[第33批](../../../wiki/raw/round-33/README.md)。本轮既有来源按原位置复用，不计作新读全文。

## 4. 可以推出什么，必须验证什么

| 表述 | 地位 | 理由／检验方式 |
|---|---|---|
| 同一关系可在不同任务、层级或期间内兼有竞争与合作 | 工作分类及可构造情形 | 明确共同产出与争取对象，不需要先设两种人格 |
| 存在共同收益，不足以推出实际参与或持续 | 条件推导与既有模型 | 还需要参与、支付、执行与维护条件；沿用Q6–Q8与重复互动模型 |
| 竞争总能选出整体更有效的组织 | 不采用普遍形式 | 被选择指标可能与任务质量、外部后果不一致 |
| 公平竞争必然最大化Ordo | 未确立 | 公平标准、能力、度量与因果连接均需分别定义 |
| 共享基础并允许方案竞争，比封闭或统一实现更能持续改进 | 待验证的领域假说 | 也可能因接口成本、知识外溢、协调失败或维护不足而失败 |
| 给竞争设置不可侵害的权利底线，并给共同维护落实责任 | 规范方向与设计要求 | 需说明权利和评价目标；不能由自然选择直接证明 |

“公平”不要求结果相等；本研究至少分别考察禁止暴力与欺骗、相关机会和信息、规则执行、进入退出、补偿申诉，并公开有争议的标准。平等条件与正当差异要在具体场景中讨论，不能预写成普遍充分条件。

## 5. 下一项可检验设计

在同一共享服务中，分别改变共同维护安排与服务商选择方式，避免只比较一个整体“开放包”和一个“封闭包”。先固定知识任务、上游投入、验收和观察期，再看质量、缺陷修复、可迁移性、重复投入、费用和分布。[制度比较协议](shared-service-institution-protocol.md)给出候选机制与记录表。

重点不是证明合作取代竞争，而是检验：哪些共同基础需要稳定合作，哪些环节适合保留竞争，哪些方法必须约束；这套组合是否比可行替代方案更能支持人的能力与持续维护。
