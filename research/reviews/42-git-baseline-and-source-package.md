# 框架基线的Git纳管与本地来源包

## 纳管内容

原创书稿、纲领与历史版本、术语和论证表、原创综述、模型程序和必要结果、筛选表、评估协议与历史审计纳入Git。完整冻结语料快照经字段检查，为本项目151份文档与193份来源元数据，不包含论文正文，作为基线证据保留。

`wiki/raw`只纳入逐项确定的书目、版本、读页、获取状态、复用关系、校验清单和研究者撰写的README；索引与五张自制模型图保留。第三方PDF、HTML、整页提取与OCR、原始对话、页面扫描和服务器响应不纳入。不是所有Markdown、TXT或JSON都适合公开，完整OCR及含原文词框的JSON按原件类别归档。

`.gitignore`按目录与具体记录用途配置，Python缓存和临时验证目录忽略；`.gitattributes`保留字节与历史换行，以免提交／检出时使既有SHA256失效。未删除或移动原始资料，未改写旧raw元数据与manifest。

## 资料包与验证

1358个原始／派生档案及检查图片另存本地ZIP，清单见[独立来源包](../../wiki/archive/README.md)。ZIP目录、CRC及每个解压后文件SHA256已检查；约275MiB的包只在忽略目录中，本地原件继续保留。它不是异地备份，也没有获得统一公开再分发许可。

检查对实际暂存或提交对象运行，区分必需仓库链接、可选来源文件与目录、原文未安装及已安装但不一致。旧历史快照保留原路径语境，公式不误算链接。另核对28单元、11章稿／论证卡、纲领0.4、79条总表和19笔资金账；不运行会改写冻结结果的历史脚本。

预提交使用索引导出的精简书稿进行检查；提交后再以不带原件的本地克隆复验，确认可选资料不在场也可阅读并通过仓库检查。流程见[版本验证说明](../../docs/repository-validation.md)。如果检查失败，先修复，再创建标签；本版检查不把理论研究和制度效果视为已证明。
