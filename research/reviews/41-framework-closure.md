## 新核算检查了什么

四个假设场景从相同总现金200开始，以19笔交易逐一核对转移和余额。参考产能100时销售92；另一场景产能140、支付分布改变后，销售68；加入指定转移或公共购买后分别为80和78。总现金都仍是200，维护8已包含在劳动支付中，不被重复计算。

它给出“产能提高不足以保证销售提高”的条件反例，并让公共资金有实际来源；不是AI收入效应估计、税率建议或全经济均衡。物质产能和行为规则是外生假设，下一期反馈另有研究责任。[结果](../surveys/08-price-income-and-reinvestment/ai-income-account-results.json)和[逐笔账](../surveys/08-price-income-and-reinvestment/ai-income-cash-ledger.csv)随程序保存。

## 对核心逻辑的反向检查

| 可能的跳跃 | 本轮处理 |
|---|---|
| 物理实现自动决定人性、目标与公平 | 明确生命和社会的新增条件，规范与意义独立论证 |
| 统一Ordo未建立，所以所有后续结论都悬空 | 列明已有结果的真实依赖；统一度量作为待验证核心，不偷作前提 |
| 一切持续结构都必须同样主动吸收能量 | 限定损耗、库存、恢复通道与时间，保留被动耐久结构边界 |
| 退出和合约模型足以处理家庭与国家 | 照护依赖、不能退出者、公共授权及问责另设接口 |
| AI提高效率，所以自然有需求、收入和维护资金 | 分开产能、付款分布、实际购买及预算，给出闭合现金反例 |
| 现金账闭合等于物理和生态可行 | 真实资源账、权利账和现金账分别检查，边界外代价保持可见 |
| 公共回流或贡献评分唯一决定正当分配 | 保留贡献归因、激励、正当回报与预算的不同责任 |
| 所需功能必要，所以Open Business唯一必要 | 保留同任务替代机制，具体优势和现实有效性继续检验 |
