# 可依赖且可修订的共同承诺

日期：2026年11月12日。性质：承接[目标冲突与修订](15-goal-conflict-and-revision.md)的定向研究与理论讨论，连接人的自我协调、共同活动和组织规则。新增来源的版本与阅读范围见[阅读记录](16-reading-notes.md)，原始材料见[第十五批归档](../../wiki/raw/round-15/README.md)。

本轮的核心判断是：共同承诺可以同时约定当前怎样行动，以及条件变化时怎样调整。可依赖性需要研究他人能够据此作出什么安排；可修订性需要研究这些安排怎样得到通知、重新协调和交接。个人改变目标、共同活动改变，以及改变是否被认可，属于不同问题。

## 从个人目标进入相互依赖

一个人可以同时追求多项目标，也可以重新评价这些目标。但当乙根据甲的承诺购买材料、保留时间或放弃其他机会时，甲是否继续履行就影响乙的可行选择。此时需要解释的对象已经包括双方之间的依赖关系。

这不要求两个人具有相同的人生目标。甲可能希望取得报酬，乙希望完成作品；双方仍可以围绕交付形成共同安排。相反，两人都希望作品完成，也可能对各自负责什么、何时算完成没有一致理解。

先区分六个层次：

| 层次 | 要研究的对象 | 单独不能保证什么 |
|---|---|---|
| 目标相容 | 双方所求结果能否同时实现 | 不保证彼此知情或协调行动 |
| 共同意向 | 各自如何理解正在一起做什么及角色关系 | 不自动确定全部义务、争议处理或法律效力 |
| 可识别的约定 | 双方实际确认了哪些任务、条件与调整安排 | 不保证资源充分或愿意履行 |
| 实际履行能力 | 时间、技能、支持、替代路径是否可用 | 不保证能力会用于履约 |
| 可信预期 | 结合能力、动机、记录和执行机制，别人怎样判断后续行为 | 不等于行为值得赞许，也不保证判断准确 |
| 规范责任 | 什么理由支持要求履行、解释、修订或补救 | 不能仅由行为频率或物理可行性确定 |

法律可执行性还需独立的领域研究，本轮不对任何现行法作判断。单方承诺与双方共同约定也不合并：一个人可以向别人承诺，双方互相承担行动责任则增加了相互协调的问题。

本轮暂以“双方可相互识别地接受一项活动中的行动责任”作为研究共同承诺的工作入口。它不是所有承诺的充分定义，也不规定所有共同活动都必须先有正式协议。默契、习惯与隐含规范同样可能组织活动，但需要另行识别其形成和边界。

## 已有证据支持什么

Hamann、Warneken与Tomasello的儿童实验，把“自己已得到奖励后，是否继续帮助共同活动中的伙伴”与非共同活动的帮助情境比较。研究一包括48名儿童、24对熟悉的伙伴。3.5岁组在共同活动条件下更常立即帮助，2.5岁组没有表现出同样的条件差异。[L74原论文](https://doi.org/10.1111/j.1467-8624.2011.01695.x)。

这提供了一个可观察的区分：完成自己的部分所得，与把共同活动进行到伙伴也取得所得，可能对应不同的行为安排。行为差异并未唯一识别内在的义务感；论文讨论了注意与互惠等替代解释。年龄比较也不是随机操纵年龄，不能将结果写成人性年龄定律，更不能给较少帮助的儿童作善恶评价。

Hart与Moore研究不能把所有相关情形写成可由外部验证条款的合同。在其模型中，当事人可以掌握相同信息，但难以向外部裁定者证明；修改安排及其信息传递方式会影响可实现的分配。[L73原论文](https://doi.org/10.2307/1912698)。

该模型的重要提醒是：事后能够重新谈妥，不等于事前有充分动力投入。它使用关系专用投资、特定交易技术等条件，且假设重新谈判无成本、没有有限理性问题；不是现实组织调整程序的完整模型。本轮采用其问题区分与限定结果，没有复现全部定理。

既有L37的IAD框架继续提示把实际规则、行动情境、信息与结果联系起来。它不要求所有参与者只关心金钱，也不把共同治理设为通用答案。本轮没有新增读取L37段落。[既有笔记](07-reading-notes.md)。

## 当前行动与改变行动的约定

可修订承诺的一个候选结构，是同时说明两个层面的内容。第一层安排当前任务：谁在什么期限内提供什么，依赖哪些条件，怎样确认完成。第二层安排变化：怎样报告困难，哪些调整已经被允许，哪些需要重新协商，协商期间依什么安排继续，怎样交接或退出。

第二层并不意味着一切变动都必须重新征得所有人的同意。双方可以事先接受一定范围内的调整，也可以约定期限、通知期或有界的退出条件。涉及他人已接受安排的实质改变，应按所采用的规范和程序判断；本轮不设无限否决权或不可退出关系。

| 约定的内容 | 它解决的问题 | 仍需观察的条件 |
|---|---|---|
| 任务范围与角色 | 限定别人可以依赖什么 | 双方理解是否一致，角色冲突是否可见 |
| 时间与支持条件 | 区分承诺的范围和超出范围的要求 | 实际能力、资源和环境变化 |
| 完成与质量判断 | 使执行与偏离能够被识别 | 判断成本、指标失真、隐蔽努力 |
| 通知与复核 | 使困难进入共同判断 | 是否及时、诚实，是否有能力处理信息 |
| 修改权限与接受方式 | 限定什么可以单方调整或需重新确认 | 权力分布、拖延、策略性利用规则 |
| 过渡 替代与退出 | 在改变后重建可行安排 | 交接能力、备用投入、不可恢复损失 |

这些是比较机制的研究维度，不是要求所有家庭、朋友关系和公司采用同一套书面程序。重复关系可能依赖熟悉与默契，大型协作可能需要记录与专门角色；哪种安排合适，取决于任务、风险、信息与维护代价。

承诺的持续也不要求原有动机不变。甲不再喜欢某项活动，仍可能通过调节时间、改变手段或经认可的替代者完成已接受的任务。反过来，甲仍认同共同目标，却可能因资源不足而无法继续。动机、能力、行动结果分别记录。

## 一个共同学习的例子

设甲乙约定共同准备一场公开课程：甲完成材料，乙根据材料准备演示。甲后来获得更重视的学习机会，想改变原计划。

若甲只修改自己的日程，乙的演示安排可能失去所需输入。若约定甲必须永远按最初办法做，新增机会和真实困难又无法进入共同决策。候选比较方案是：限定本次课程的交付内容与时间；提前报告变化；在既定范围内换用其他制作方法；超出范围时协商延期、缩减内容或认可的交接，并说明过渡期间谁继续提供支持。

这里可能保持的是乙能够使用的材料及双方对交付的理解，而不是甲最初的全部行动路径。若内容本身也需改变，就需重新处理乙已经准备的部分。调整是否值得，还应考虑受课程影响的其他人，而不只看甲乙是否同意。

## 两个有限的条件论证

### 改变个人计划可能改变别人的可行集合

设乙在期限T前完成任务，必须取得甲的一项输入；在该期限内没有可用替代，也不能改变任务所需条件。若甲撤回该输入，乙就无法按原条件完成任务。这是依赖定义下的直接结果，不是对所有合作的经验定律。

要恢复可行性，至少需要改变某个条件，例如恢复原输入、提供实际可用的替代、延长期限或修改任务要求。“我已经不想做了”本身不提供缺失输入。这只说明因果后果，不直接推出甲在伦理上必须继续、谁应付出多少补救费用。

### 修改安排的净收益与参与激励分开

在一个简化核算中，设一期发生需调整事件的概率为q。没有调整机制时，每次事件造成可避免损失L；有机制时，每次需付协调交接成本h，并留下剩余损失g；无论是否发生事件，维持机制都需成本k。所有量按同一声明的可比成本尺度估计，其余后果相同。

原方案期望成本为qL，新方案为k+q(h+g)。因此，新方案按此准则更合算，当且仅当q[L−h−g]>k。这里尚未给q、L、h、g、k任何现实估计。

该式揭示需要测量什么，不证明有程序就更好。如果机制延误预警、鼓励任意重谈，或损失不能合理相加，这个模型就需改写。即便总成本降低，承担k和h的人也可能没有得到相应收益，因而不愿参与或执行。总收益、分配、激励、预算及执行仍分别检验。

## 可靠性与修订可能彼此支持也可能冲突

允许及早报告并按已接受条件调整，可能使当事人更愿意接受有边界的责任，给伙伴留下寻找替代的时间；这是值得验证的机制假说。如果报告带来惩罚、协商没有结果或备用能力不存在，通知也不自动解决问题。

另一方向是：甲为合作预先学习专门技能，投入后才发现乙可以利用甲缺少替代机会重新压低回报。即使后来双方仍能成交，甲事前也可能减少投入。Hart与Moore提供了研究这种跨期差别的特定模型，不能将“事后允许改约”一律评价为更自由或更有效。

研究因此需要同时问：哪些改变有助于适应实际条件；哪些改变只是把成本转给依赖者；怎样限制事后利用又保留必要的调整机会。规则本身也有制定、解释、记录与维护成本。

## 在通用组织理论中的地位

这里可以建立一条有条件的连接：个人具有变化的目标与能力；相互依赖使这些变化影响他人的行动条件；沟通、角色安排与修订规则可能支持共同活动持续。每一环都需要自己的定义、领域假设或证据。

有共同目标不是组织存在的一般前提。相互竞争甚至具有支配关系的成员也可能构成有组织系统。能够持续的内部承诺也可能伤害外部人，不能以稳定合作直接定义善。

物理可行性约束行动，信息描述与预期描述帮助分析协调；它们不能单独给出责任、公平或退出权的内容。若用“熵秩”描述共同能力，应先说明所维护的任务与关系、时间范围及代价，不能以低熵直接推出守约义务，也不能把可信性写成已经确立的统一Ordo量值。

| 候选表述 | 当前地位 | 仍需明确什么 |
|---|---|---|
| 个人目标 共同意向 可识别约定 可信预期与规范责任分开 | 工作定义及分析约定 | 隐含承诺、单方承诺与各领域用法 |
| 人的目标和能力会变化，任务可能相互依赖 | 人类协作领域假设 | 变化频率、依赖程度、实际替代与退出条件 |
| 必要输入撤回且无替代会破坏原任务可行性 | 已列前提的逻辑结果 | 不能直接推出义务与补偿标准 |
| q[L−h−g]>k对应简化模型的净成本改善 | 条件性核算 | 同尺度、其余后果相同、变量估计与分配机制 |
| 事后可调整可能与事前投入激励冲突 | 既有模型的限定结论及研究入口 | 实际议价、信息、可验证性和替代机会 |
| 明确的有界承诺与修改规则改善持续合作 | 待验证假说 | 与默契、僵硬约定及无约定的比较，长期质量与成本 |
| 给依赖者合理预期，同时保留修订和退出空间 | 本项目可讨论的规范目标 | 权利范围、受影响者、权力及成本分担的理由 |
| 通知时限 复核频率 备用资源与交接标准 | 应用参数 | 按任务估计，不设通用最优值 |

上述条目未并入正式79条总表；本轮没有增加普遍公设，也未把共同承诺确立为所有复杂组织的必要特征。

## 下一项可检验问题

可先比较一类有先后依赖的共同任务：无明确修改安排、固定安排、事先接受修改与交接条件的安排。记录初始投入、完成质量、预警提前量、协调及备用成本、损失由谁承担，以及改变后是否愿意继续合作。参与者原有关系、资源和选择机会需要控制或分别记录。

重点区分透明信息的作用、真实备用能力的作用与修订权限的作用；不能把同时增加这些因素后的变化全归因于开放或信任。若增加的维护成本抵消损失减少，或有规则却仍少投入、损失集中于弱势一方，候选假说就需缩小范围或修改。

继续追问的重点是：**当双方对“是否已经履行”“改变是否合理”意见不同时，谁来解释和修改规则，这种权力本身又怎样受到约束？** 这把共同承诺接到规范、权力与组织治理，而不预先选择Open Business作为唯一结论。

按用户进一步追问到人的意义的要求，该连接现已扩展为[从共同承诺追问到人的意义](17-commitment-authority-and-meaning.md)，依次讨论授权、共同目的、个人生活与意义评价，未把哲学回答升级成普遍公设。
