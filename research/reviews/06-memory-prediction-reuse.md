# Q5 记忆预测与复用的研究结论

日期：2026年11月11日。状态：工作区分与条件性命题，供讨论。

记忆可以保留过去的成果，预测可以改变行动，复用可以避免重复投入；这些效果都需要与任务、环境变化、可行策略及全周期成本连接。通用组织理论可以研究这种连接，不必先规定“记忆必然使组织程度单调增加”。

本轮依据[四项新增原文与既有复用线索](06-reading-notes.md)，并建立[三组最小模型和共享错误对照](06-memory-reuse-models.md)。软件复用的系统综述及现实案例尚未完成，全文获取失败的材料未作证据。

## 需要分别描述的能力

| 概念 | 工作含义 | 不能直接等同的量 |
|---|---|---|
| 记忆 | 当前内部状态保留过去条件的影响，并可在之后发挥作用 | 存储容量、当前状态熵、关于任务的有效信息 |
| 预测信息 | 指定记忆或过去记录与指定未来变量之间的统计信息 | 预测器已经掌握规律、实际预测准确率、行动收益 |
| 预测器 | 根据当前可用记录生成对未来的判断或分布的机制 | 所有内部状态或任意反馈回路 |
| 显式内部模型 | 系统内部可辨认地表示对象、规律或状态转换，并用于推演的机制 | 一切与未来相关的物理状态；不以主观意识为前提 |
| 复用 | 在新的任务实例中使用既有成果、规则、表示或部件 | 原样复制、零成本执行、结果必然有效 |
| 有效积累 | 在声明的任务集合、期限和预算下，可用能力或净收益得到保留和增加 | 文件数量、记录总量或状态空间扩大 |

这些是对子类机制的工作描述，不把所有广义组织都定义成必须有记忆和预测器。记忆需要因果路径与保存机制；单纯统计相关性不是全部识别证据。涉及“知识”时，还应另记其内容、适用范围、来源、可靠程度和更新条件，不能仅用 bit 数代替。

## 从保存记录到任务表现的连接

一个可用于记忆系统的描述是：观察 Y_t 通过更新机制改变内部状态 M_t，状态与观察共同影响行动 A_t；行动又通过具体过程改变任务结果。比较时需说明各时刻可获得的信息，不能把事后数据交给当时的策略。

保存、读取、推断、决策、执行和更新分别可能成为限制。现实组织可能反过来改变环境，本轮最小模型的环境均由外部给定，因此主动感知和环境改造不能从这些模型直接推出。

### 记录完好仍会过时

二态环境模型中，系统完好保存过去一个 bit，其边际熵始终为 1；随着环境转移，关于当前状态的互信息可以趋近零。这里衰退的是记录与目标的关系，不是保存内容本身。

这一例子也不意味着免费增加记录必然降低信息量。对同一个未来目标、同一概率描述和嵌套记录集合，增加可用记录不会减少互信息；若允许原策略免费忽略新增记录，也不会降低最优可达收益。现实中存储、检索和适配有成本，才需要比较具体的净收益。

### 预测整体环境未必帮助当前任务

如果记录预测的是与任务无关的环境部分，即使它对未来环境含有正互信息，也可能不提高任务成功率。需要先说明预测什么、何时行动、能改变什么，以及如何评价后果。

### 有用线索也可能被错误使用

对数增长例子中，同一条正确率 80% 的线索，采用匹配其可靠度的分配策略得到正增益；将 99% 的总量都压到线索指向的类型，结果反而低于不利用线索的基准。这是策略失配造成的损失，不能说成互信息本身有害。

## 信息价值可以怎样严格连接

### 给定任务的决策价值

对于有限状态和行动，给定真实联合分布 P(X,Y)、效用 u(a,x)，没有信息与允许使用线索 Y 的最优值之差为：

\[
\Delta V=\mathbb E_Y\left[\max_a\mathbb E[u(a,X)\mid Y]\right]
-\max_a\mathbb E[u(a,X)].
\]

在信息免费、允许保留原行动策略且比较相同可行行动时，ΔV≥0：无信息最优行动在每个 Y 下仍可采用，其期望值没有消失。这个不等式是策略集合包含关系带来的数学结果，不要求“信息越多越符合所有目标”。

实际是否值得获取，还需减去用同一效用尺度表达的获取、检索、维护、推断与实施代价，并考虑模型估计是否正确。不能不经映射就把物理能耗、工时和社会利益相加。多目标与不同主体的评价可能不一致。

### 对数增长下的互信息与 KL

Kelly 与 Rivoire、Leibler 的工作展示了严格联系的一种来源。对特定环境、共同线索、匹配型繁殖或回报以及比例分配策略，最优信息增益可等于 I(X;Y)，策略失配的损失可写成条件 KL 的平均。

这个关系解释了信息在某类机制中怎样产生可计算收益，不是直接给 bit 标一个通用价格。放松群体共同线索、跨代记忆、可行行动和繁殖结构后，需要重新推导；L30 尤其区分个体信息与群体收益。普通期望效用、长期对数增长、平均总产出和最坏情形保障也不能混用。

### 预测与耗散的物理联系

L31 给出另一种严格连接。在其热浴、无系统反馈的随机驱动、物理 Markov 响应及功步骤与弛豫步骤的设定下，记：

\[
I_{\rm mem}(t)=I(S_t;X_t),\qquad
I_{\rm pred}(t)=I(S_t;X_{t+1}),\qquad\beta=(k_BT)^{-1}.
\]

文中驱动改变步骤满足：

\[
\beta\langle W_{\rm diss}^{\rm step}\rangle
=I_{\rm mem}(t)-I_{\rm pred}(t).
\]

整个协议的平均耗散还包括弛豫贡献，文中得到：

\[
\sum_t[I_{\rm mem}(t)-I_{\rm pred}(t)]
\le\beta\langle W_{\rm diss}\rangle
\le\beta\langle W_{\rm ex}\rangle.
\]

这些信息量使用自然对数；若换成 bit，需要相应 ln 2 因子。这里按文中的条件自由能与过程定义理解分步耗散，不把任意两个互信息的差都当成普遍非负的信息份额，也不把分步等式替换为总耗散等式。

这为预测与热力学效率提供了物理机制，同时没有证明所有复杂群体都采用该过程。项目的二态记忆和复用模型未指定物理能级及热浴实现，不能直接将其中 bit 数按此公式换算耗电。Q3 关于不存在由复位下限推出的固定每 bit 每秒维持费的判断保持不变。

## 复用需要全周期比较

本轮比较相同的任务次数与正确输出要求，分别计算每次从零、检查整项成果后更新、逐模块检查更新，以及允许过时错误的不检查方案。

在两个子成果独立失效、检查完美、更新正确的模型中，整项成果复用优于从零生成的条件是：

\[
F<(H-1)[Cs-m-v],
\]

其中 F 为初次整理投入，H 为使用次数，C 为从零生成代价，s 为一次间隔后整项成果仍有效的概率，m、v 为每次后续使用所需维护和检查代价。必须先有正的单次节省余量，再有足够使用次数。

对给定示例参数，任务很稳定时整项缓存较省；局部经常改变时，模块化更新节省重复重建；所有部分每次均失效时，检查复用反而更贵。结论来自明示的成本与失效结构，不是复用本身必然带来收益的公理。

检索也可能成为负担。本轮顺序扫描的例子中，增加无关候选提高检查成本；更好的索引和筛选会改变这种结果，不能据此宣布所有知识库越大越低效。

### 遗忘更新与锁定

停止读取、重建索引、迁移表示、更新内容和物理删除是不同措施，应各自比较代价；过时不意味着必须立即擦除全部记录。

转换成本和剩余使用期可以使继续旧方案暂时合理。若旧架构、配套技能或兼容要求改变了后续可行选择与转换成本，就需要把历史状态纳入路径依赖模型。已经付出的初始投入是沉没成本，不能不加区分地再次计为未来切换损失。本轮给出简单切换阈值，没有证明一切记忆必然导致锁定。

### 信息杠杆的候选操作化

可以在同一任务、质量、期限与预算约束下，记录净节省 ΔC=C_baseline−C_strategy，或在分母为正时记录成本比 C_baseline/C_strategy。必须列出比较基准、使用次数及成本边界。

这些指标依赖情境，不是成果自带的恒定倍增系数。同一程序在重复任务中可能节省成本，在新环境中却需要重建。性能、可靠性和成本无法合并时，分别记录，不强行生成一个普遍 Λ 或 Ordo。

## 共享的收益与共同风险

共享成果可能减少重复生成和集中验证投入，但其有效版本、适配与维护仍要持续实现。同一成果影响许多使用者时，错误之间的相关性也可能变化。

在本轮共同错误例子中，单个使用者错误率和期望受影响人数相同，共用一个错误源却显著提高全部同时受影响的概率。它不证明共享总体更危险：集中测试和修复也可能降低单个使用者的错误率，需要与相关结构一起测量。

因此未来评价开放共享时，除复制成本和使用量，还应记录适用范围、版本、验证覆盖、更新到达率、共同依赖、维护投入及风险分布。这些是后续领域模型的测量方向，尚不是 AutoOS 的实际运行结论。

## 对旧讨论的处理

历史背景为 H01 第 1526–1542、1570–1576 行附近的内部模型与记忆叙述，以及[首次审查 C12、C13](01-claim-audit.md)；它们是待审查的思想来源。

| 旧主张 | 当前判断 | 后续可研究的形式 |
|---|---|---|
| 秩超过统一阈值必然产生内部预测模型 | 对组织量、阈值、显式模型和形成机制的定义均不足 | 在给定环境相关性与资源成本下，比较具体记忆及预测机制 |
| 记忆使组织能力只能累积 | 无一般单调性支持 | 区分保存量、适用性与净收益，加入失效、误用、维护及遗忘 |
| 保留信息就会改善未来决策 | 缺少任务及行动条件 | 指定预测目标、行动映射、策略估计与成本 |
| 复用自然形成无限杠杆或必然指数增长 | 特定放大与增长模型的过度推广 | 说明重复任务、使用次数、质量约束、反馈及资源边界 |
| 信息热力学意味着复杂系统必然升级为 ProActive | 从物理效率关系跳到演化必然性 | 区分隐式相关、显式推演与能够产生相应结构的选择过程 |
| 知识越集中或共享越多，净收益必然越大 | 缺少成本与风险分布 | 比较检索、适配、维护、重复投入及共同失效 |

本轮说明某些无条件主张缺少推导，并给出特定模型的反转情形；不声称已经证明所有可能的统一记忆理论或内部模型理论都不成立。

## 公设与命题的地位

| 地位 | 当前处理 |
|---|---|
| 工作定义和描述约定 | 明确记录、任务、预测期限、信息到达时间、策略与成本边界 |
| 继承的数学和物理结果 | 在原有条件下使用互信息、KL、最优决策包含关系、对数增长联系和耗散关系 |
| 条件性模型命题 | 记录年龄的作用、失配损失、复用阈值及共同错误的概率结构 |
| 需要经验检验的假说 | 哪些现实组织确实借助这些机制提高表现，预测、维护和更新投入如何测量 |
| 需要新增社会假设的问题 | 谁维护知识，谁付费，谁有权使用，如何分配收益和处理外部影响 |

本轮不新增“记忆必然积累”或“高阶组织必然预测”的通用公设。形成机制、可用能力与被选择的价值目标继续承担各自的解释责任。

## 后续研究接口

Q1 至 Q5 已形成第一阶段的工作基础：关系与边界、维持路径、度量、模块接口、记忆与复用。它们仍是有限研究结果，尚未合成一篇完整系统综述或验证过的通用理论。

下一步建议进入 Q6，先建立从通用模型到社会经济的变量映射与新增假设表：主体有哪些选择，谁承担成本，谁取得成果，哪些成果可共同使用，规则怎样执行。选择“共享成果的维护与回报”作为连接案例，可以沿用本轮生命周期成本，再引入参与、融资和激励；不预设 Open Business 必然优越，也不把技术净节省直接当成任一主体的收入。
