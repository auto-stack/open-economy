# Q6 从通用组织模型进入社会经济

日期：2026年11月11日。状态：第一轮定向研究与条件性模型，供讨论；没有修改纲领为定稿公设。依据见[阅读笔记](07-reading-notes.md)与[模型推导](07-economic-bridge-models.md)，新增原文见[本地归档](../../wiki/raw/round-07/README.md)。

## 本轮回答

通用组织理论可以保留，但进入社会经济领域时，需要显式增加主体、行动、偏好、信息、权利、承诺与执行机制。基础物理规律约束这些过程的实现；现有物理约束与前几轮的一般组织模型，还不足以唯一确定谁愿意做什么、成果怎样计价，以及怎样分配才应当被接受。

这里指出的是目前论证链缺少哪些条件，不是断言人类行为不属于物理过程，也不是证明更深层理论永远不可能建立。跨领域推广要提供变量映射、因果机制和可检验结果，不能只更换术语。

本轮的连接链为：**维护能力怎样依赖投入 → 谁能控制投入、谁受益 → 在哪些信息和规则下行动 → 哪些结果能实现并持续 → 按什么标准评价**。Open Business 是最后几步中的候选制度应用，不是前三步已经推出的结论。

## 1 通用描述如何映射

| 通用组织描述 | 经济分析中需要明确的对象 | 不能直接等同的项目 |
|---|---|---|
| 节点、组成部分 | 能作何种决策的主体、角色和代表关系 | 每个物理节点都具有独立目标或选择权 |
| 系统边界 | 技术边界、受益范围、收付款范围、成员与规则范围 | 一条网络边界就是一家企业或共同体 |
| 状态与能力 q | 在指定任务中的服务质量、可用性和产出 | 能力、成本、成交价格、社会价值是同一量 |
| 资源与损失 | 时间、设备、能量、技能和机会成本 | 能量单位自动变成货币单位 |
| 记录与信息 | 可获得、可理解、及时、可核验的信息和报告 | 某处存在的记录就是所有人可用的知识 |
| 接口与耦合 | 交付条件、权限、承诺、责任与执行 | 技术上可调用就有权使用，或承诺必然履行 |
| 维护过程 | 谁选择投入，谁观察质量，谁承担风险 | 资金到位就保证努力和目标质量 |
| 持续与稳定 | 状态稳定、预算可续、行为均衡、成员接受 | 动力学稳定证明财务或制度可持续 |
| 整体表现 | 各方收益、外部影响、分布与评价标准 | 整体指标增加证明所有人受益或分配公平 |

Q1–Q5 的状态、关系、任务、反事实与全周期成本方法可以延用。社会经济对象需要更细的角色与信息描述，特别是“维护者”“使用者”“出资者”“规则制定者”可能由不同人承担，且一个人可以占多个角色。

## 2 定义、公设候选与待证命题的地位

| 项目 | 建议地位 | 论证责任 |
|---|---|---|
| 明确组成、关系、边界、状态、环境和考察期限 | 通用描述要求的候选 | 说明选择理由、可观测量与替代划分 |
| 物理实现服从相应物理规律 | 物理约束 | 写明适用条件、资源边界与单位，不自行推出行为定律 |
| 社会经济主体具有不同可选行动、信息与后果 | 领域描述框架 | 指定角色、选择权限和行动如何作用于结果；不是说所有组织节点都有意图 |
| 偏好、信念、资源禀赋、退出选择、动机 | 领域模型假设及经验对象 | 不能默认相同、固定或完全已知，应说明数据或作敏感性分析 |
| 完全自利、完全理性、完全信息、共同先验 | 可选简化假设 | 有限模型中声明，不能作为复杂组织的普遍公设 |
| 使用不减损、排除难度、拥挤和可复制性 | 成果及服务的属性 | 拆开具体组成，随技术、规模和规则核查 |
| 权利、支付、质量承诺、监督、制裁与规则修改 | 制度模型及经验对象 | 描述实际运行方式和成本，不能把规则文本当作执行结果 |
| 预算平衡、参与约束、激励相容 | 给定机制的检验条件 | 先定义时期、状态、外部选择和均衡概念，再推导是否满足 |
| 等权总收益、平等、普惠、自主、开放 | 评价基准或规范目标 | 明确谁的利益被计入、怎样权衡；不从熵增推出正当性 |
| 开放共享产生净收益、合作扩大能力、开放商业可持续 | 待推导、待检验的条件性命题 | 比较具体替代方案，计入运行成本与失败条件 |

建议把基本框架保持为能容纳不同机制的语言，而把强行为主张放到模型层。Ostrom 对框架、理论和模型的区别提供了可借鉴的做法；本项目尚未因这一借鉴而获得通用组织理论的验证。

## 3 共享成果不是一种单一物品

Samuelson 的共同消费模型与 Ostrom 的属性分类提示：需要分开“能否排除未付费者”与“一人的使用是否减少其他人的可用量”。二者都有程度和情境差异。

| 属性组合 | 常见分析对象 | 在数字协作中的可能对应 |
|---|---|---|
| 容易排除，使用会减损 | 私人品 | 专属工时、设备时段 |
| 容易排除，低拥挤时使用较少减损 | 俱乐部/收费品 | 有访问控制且容量充足的服务 |
| 难以排除，使用会减损 | 公共池资源 | 开放使用但会耗尽的共享容量或资源 |
| 难以排除，使用较少减损 | 公共品 | 某些已公开且容易传播的知识成果 |

这只是属性示例，不是法律分类。代码、文档的复制可能近似非竞争，但维护工时、算力、带宽、响应服务会被耗用或拥挤。可复制不等于零制作成本，公开访问不等于无权利、无规则或无人维护。现实系统通常是这些成分的组合，不能只给整个项目贴一个“公共品”标签。

知识分散还增加了一个 Q5 未处理完的问题：即使记录存在，局部条件也可能难以传递；有时掌握者还不愿如实披露。Hayek 的知识问题与本轮申报反例分别提示可用性和激励两种障碍，它们不能由一个信息量指标概括。

## 4 三种缺口的最小演示

详见[方程、假设和可复核数值](07-economic-bridge-models.md)。下面只列模型在已声明条件下说明的区别。

**能力与行动的缺口。** 对同一维护规律，四名受益者只考虑自身收益时，稳态能力为0.655301；等权总体最优为0.770781。后者在无额外规则时允许个人有利偏离。若改变对他人收益的关心程度，均衡也改变。因此，技术上能够做到与当前规则下会做到有别。

**总收益与参与的缺口。** 一项成果价值分别为6、4、2，供给成本9，等额收3会使第三人在“退出即不供给”的协议下不愿参加。分摊5、3、1可以兼顾预算和这种参与约束。特设贡献博弈既有不供给均衡，也有供给均衡；正净收益不能代替协调过程，搭便车也不能被宣布为不可避免。

**资金与执行的缺口。** 固定给维护者4可以覆盖高努力成本，却在例子的隐藏行动条件下不能激励高努力。成功奖金在适当区间可以提供激励，但管理成本、现金需求与结果可核验性限制可行范围。Holmström 的团队研究提示激励问题的重要性，本轮单人例子不是其团队定理的复现。

附加申报例子表明，公开分摊公式仍可被策略性低报利用；附加定价例子表明，可排除访问的统一价格也未必覆盖成本。这些都是具体机制结果，不能推出某一制度普遍优越。

## 5 后续制度方案至少检查什么

1. **技术与资源可行性**：成果怎样生产和维护，物理投入、容量与能力目标是否匹配。
2. **资金与预算**：谁在什么时点、什么结果下付款，是否有储备、亏损承担者和周转安排；预期收支不是每种状态下都能支付。
3. **参与选择**：每方相对真实外部选择是否愿意加入和留下。公共成果若在其退出后仍可使用，退出收益可能为正，不能总设成0。
4. **行动和报告激励**：期望的努力、质量、披露及贡献申报能否在实际规则下实现；个体和联合偏离需分别研究。
5. **信息与执行**：哪些事实能观察、核验、据以兑现承诺，监督和争议处理要花多少资源。
6. **评价与治理**：谁受益、谁承受风险，规则由谁决定和修改，怎样处理异议、退出和未被代表的外部影响。

这些是分析维度，不是已经证明充分的稳定条件。短期通过它们还不能保证学习、环境变化与跨期承诺下的长期持续。这里的参与约束和激励相容也只有在相应行动、外部选择、信息和均衡概念已定义时才有明确含义。

财务账户与真实投入账户应同时保留。在包含交易双方的边界内，支付是转移；材料、工时和管理投入有真实成本。把支付与它购买的投入重复扣除会误算总收益，但只看总收益又会掩盖缺钱、分配和退出问题。

## 6 对旧讨论的处理

- **C08 合作一定形成更高阶组织**：共同利益可能存在，但能否形成稳定关系还取决于承诺、参与、激励和治理。合作、竞争可以在同一项目的不同关系上并存，不能只凭负熵来源定义两者。
- **C06 技术封装与企业层级**：技术模块不能自动确定交易边界、控制权和企业形式。接口、交易成本与内部协调成本需要分别分析。
- **C12、C13 信息杠杆与积累**：Q5 已限定任务收益，Q6 进一步区分收益落到谁、谁支付、能否执行。集体节省不能直接作为维护者收入。
- **能力、价值与贡献分配**：投入量、因果贡献、需求者愿付额、实际价格及应得份额不相同。没有在本轮找到把它们统一换算成 Ordo 或能量的依据。
- **开放必然最优**：开放可作为规范目标，也可作为待检验设计；其效果要与同等质量、同等边界下的替代制度比较，不能由热力学开放性直接推出。

因此不新增“所有人自利”“合作必有更高阶组织”“市场价格等于全部价值”或“开放商业必然胜出”等公设。保留通用框架与开展领域假设研究是相容的路线。

## 7 下一步 Q7 的研究接口

以一项有明确维护任务的共享成果为对象，比较自愿贡献、条件承诺筹资、成员/补充服务、赞助等有限方案。各方案采用相同质量、使用范围与时间边界，再分别列资源、资金、参与、报告、努力和治理条件；若研究公共融资，另补其决策和执行机制的文献。

重点问题应从“开放是否天然有利”改为：**当维护成本、收益分布、信息与规则成本给定时，哪些机制能让共同使用的成果获得持续投入，各自在哪些条件下失效？**

这仍是机制比较的起点，尚未证明任何真实方案最佳。Q8 再将比较条件映射到 AutoOS 的实际角色、收支、贡献识别和治理；历史讨论中的具体比例不是本轮基础假设。当前不急于写书籍正文或固定商业费率。
